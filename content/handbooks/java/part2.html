Production control flow should optimize readability first, then performance. Prefer expressive switch patterns, guarded branches, and clear loop boundaries. Bugs in branching logic are among the most expensive to diagnose in large Java services.

Hindi mein samjhoReal projects me control flow ka goal readable aur predictable code hota hai. Clear branching aur loop boundaries se debugging aur maintenance dono easy hote hain.

2.1

Conditionals — if / else if / else, nested conditions

Making decisions in code

Java uses if, else if, else for conditional branching. Conditions must be boolean expressions — unlike Python, 0 and "" are NOT falsy in Java. Use && (AND), || (OR), ! (NOT) for compound conditions. Ternary operator ? : provides inline conditionals.

Hindi mein samjhoJava me if, else if, else conditional branching ke liye use hota hai. Conditions boolean honi chahiye — Python ke unlike, 0 aur "" falsy nahi hain Java me. Compound conditions ke liye &&, ||, ! use karo.
💻 Java — Conditionals
int age = 20;

// Basic if-else
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

// if-else if-else chain
int score = 85;
if (score >= 90) {
    System.out.println("A Grade");
} else if (score >= 80) {
    System.out.println("B Grade");
} else if (score >= 70) {
    System.out.println("C Grade");
} else {
    System.out.println("Fail");
}

// Compound conditions
boolean hasID = true;
if (age >= 18 && hasID) {
    System.out.println("Entry allowed");
}

// ⚠️ Java does NOT have truthy/falsy like Python!
// if (0)  → ❌ Compile error! Must be boolean
// if ("") → ❌ Compile error! Must be boolean
if (age != 0) { // ✅ Explicit boolean check
    System.out.println("Age is not zero");
}

// Ternary operator
String status = (age >= 18) ? "Adult" : "Minor";

// Nested ternary (avoid — use if-else instead)
String category = (age < 13) ? "Child"
               : (age < 18) ? "Teen"
               : "Adult";
Java vs Python: Java conditions must be boolean. if (0), if (""), if (null) are all compile errors. Always use explicit comparisons: if (str != null && !str.isEmpty()).
2.2

switch — traditional, enhanced switch expressions (Java 14+)

Multi-way branching

Traditional switch uses case + break. Java 14+ adds switch expressions with arrow syntax (->) — no break needed, and they can return values. Switch works with int, char, String, and enum. Java 21+ adds pattern matching in switch.

Hindi mein samjhoTraditional switch me case + break lagta hai. Java 14+ me switch expressions arrow syntax (->) ke saath aaye — break ki zaroorat nahi, aur values return kar sakte hain. Java 21+ me switch me pattern matching bhi hai.
💻 Java — switch Statement & Expression
// Traditional switch (break required!)
int day = 3;
switch (day) {
    case 1: System.out.println("Monday"); break;
    case 2: System.out.println("Tuesday"); break;
    case 3: System.out.println("Wednesday"); break;
    default: System.out.println("Other");
}

// ⚠️ Fall-through bug (missing break)
switch (day) {
    case 1: // Falls through to case 2!
    case 2: System.out.println("Mon or Tue"); break;
}

// ✅ Enhanced switch expression (Java 14+)
String dayName = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    case 4 -> "Thursday";
    case 5 -> "Friday";
    case 6, 7 -> "Weekend";  // Multiple labels!
    default -> "Invalid";
};  // Semicolon after expression!

// Switch with String
String command = "start";
switch (command) {
    case "start" -> System.out.println("Starting...");
    case "stop" -> System.out.println("Stopping...");
    case "restart" -> {
        System.out.println("Restarting...");
        // Multi-line block
    }
    default -> System.out.println("Unknown");
}

// yield — return value from block in switch expression
int numLetters = switch (dayName) {
    case "Monday", "Friday" -> 6;
    case "Tuesday" -> 7;
    default -> {
        int len = dayName.length();
        yield len;  // yield instead of return!
    }
};
FeatureTraditional switchSwitch Expression (14+)
Syntaxcase X: ... break;case X -> ...
Fall-throughYes (if no break)No (safe by default)
Returns valueNoYes (yield for blocks)
Multiple labelsStacked casescase 1, 2, 3 ->
ExhaustiveNoYes (if returning value)
2.3

for loops — classic for, enhanced for-each, labeled loops

Iterating through data

Java has three loop types: classic for with counter, enhanced for-each for collections/arrays, and while/do-while. Use break to exit, continue to skip. Labeled loops let you break/continue from nested loops.

Hindi mein samjhoJava me teen loop types hain: classic for counter ke saath, enhanced for-each collections/arrays ke liye, aur while/do-while. break se exit karo, continue se skip karo. Labeled loops se nested loops me break/continue kar sakte ho.
💻 Java — for Loops
// Classic for loop
for (int i = 0; i < 5; i++) {
    System.out.print(i + " "); // 0 1 2 3 4
}

// Reverse loop
for (int i = 10; i >= 0; i -= 2) {
    System.out.print(i + " "); // 10 8 6 4 2 0
}

// Enhanced for-each (arrays & collections)
int[] nums = {10, 20, 30, 40, 50};
for (int n : nums) {
    System.out.print(n + " "); // 10 20 30 40 50
}

// for-each with String array
String[] names = {"Alice", "Bob", "Charlie"};
for (String name : names) {
    System.out.println("Hello, " + name);
}

// break and continue
for (int i = 0; i < 10; i++) {
    if (i == 5) break;     // Exit loop at 5
    if (i % 2 == 0) continue; // Skip even numbers
    System.out.print(i + " "); // 1 3
}

// Labeled loops (break outer loop from inner)
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) break outer; // Exits BOTH loops
        System.out.printf("(%d,%d) ", i, j);
    }
}
// Output: (0,0) (0,1) (0,2) (1,0)

// Infinite loop
for (;;) { // Same as while(true)
    break; // Must break to avoid infinite loop!
}
When to use which loop: Use for-each when you don't need the index. Use classic for when you need the index or custom step. Use while when the number of iterations is unknown.
2.4

while & do-while — break, continue, infinite loops

Looping with unknown iterations

while checks condition before each iteration. do-while executes at least once, then checks. Use while(true) for event loops, servers, and menu-driven programs. Always ensure a termination condition to avoid infinite loops.

Hindi mein samjhowhile condition pehle check karta hai. do-while kam se kam ek baar execute karta hai, phir check karta hai. while(true) event loops aur menu programs ke liye use hota hai. Infinite loop se bachne ke liye hamesha termination condition rakho.
💻 Java — while & do-while
// while loop
int count = 0;
while (count < 5) {
    System.out.print(count + " "); // 0 1 2 3 4
    count++;
}

// do-while — always runs at least once!
int num = 10;
do {
    System.out.println(num);  // Prints 10 (even though 10 > 5)
} while (num < 5);

// Menu-driven program pattern
Scanner sc = new Scanner(System.in);
int choice;
do {
    System.out.println("1. Add  2. Remove  3. Exit");
    choice = sc.nextInt();
    switch (choice) {
        case 1 -> System.out.println("Adding...");
        case 2 -> System.out.println("Removing...");
        case 3 -> System.out.println("Bye!");
        default -> System.out.println("Invalid!");
    }
} while (choice != 3);

// Sentinel loop — read until -1
int sum = 0, input;
while ((input = sc.nextInt()) != -1) {
    sum += input;
}
System.out.println("Total: " + sum);

// Infinite loop with break
while (true) {
    String line = sc.nextLine();
    if (line.equals("quit")) break;
    System.out.println("You said: " + line);
}
LoopChecks conditionMin executionsBest for
forBefore0Known count, index needed
for-eachBefore0Arrays, collections
whileBefore0Unknown count, condition-based
do-whileAfter1Menu loops, validate-first
2.5

Pattern matching — instanceof patterns (16+), switch patterns (21+)

Modern Java type-safe dispatch

Java 16+ introduces pattern matching for instanceof — cast and assign in one step. Java 21+ adds pattern matching in switch with type patterns, guarded patterns (when), and null handling. This replaces verbose instanceof-then-cast chains.

Hindi mein samjhoJava 16+ me pattern matching for instanceof aaya — cast aur assign ek step me. Java 21+ me switch me pattern matching aaya type patterns, guarded patterns (when), aur null handling ke saath. Ye verbose instanceof-then-cast chains ko replace karta hai.
💻 Java — Pattern Matching
// ❌ Old way (Java 15 and earlier)
Object obj = "Hello";
if (obj instanceof String) {
    String s = (String) obj;  // Redundant cast!
    System.out.println(s.toUpperCase());
}

// ✅ Pattern matching instanceof (Java 16+)
if (obj instanceof String s) {  // Cast + assign in one!
    System.out.println(s.toUpperCase()); // s is already String
}

// Works with &&
if (obj instanceof String s && s.length() > 3) {
    System.out.println(s); // Safe — s.length() only if String
}

// ✅ Pattern matching in switch (Java 21+)
Object value = 42;
String result = switch (value) {
    case Integer i -> "Integer: " + i;
    case String s  -> "String: " + s;
    case Double d  -> "Double: " + d;
    case null     -> "null value";
    default       -> "Unknown: " + value;
};

// Guarded patterns (when clause)
String desc = switch (value) {
    case Integer i when i > 0  -> "Positive int";
    case Integer i when i < 0  -> "Negative int";
    case Integer i              -> "Zero";
    case String s when s.isEmpty() -> "Empty string";
    case String s               -> "String: " + s;
    default                     -> "Other";
};
FeatureJava VersionSyntax
instanceof + castJava 1if (obj instanceof String) { String s = (String) obj; }
Pattern instanceofJava 16if (obj instanceof String s) { ... }
Switch type patternsJava 21case Integer i -> ...
Guarded patternsJava 21case Integer i when i > 0 -> ...
Null in switchJava 21case null -> ...
2.6

Strings — String, StringBuilder, immutability, methods

Text processing in Java

String is immutable — every modification creates a new object. Use StringBuilder for mutable, efficient string building (loops, concatenation). Compare strings with .equals(), never ==. Java strings are UTF-16 encoded and support Unicode.

Hindi mein samjhoString immutable hai — har modification naya object banata hai. Mutable aur efficient string building ke liye StringBuilder use karo. Strings compare karne ke liye .equals() use karo, kabhi == nahi. Java strings UTF-16 encoded hain.
💻 Java — Strings
// String creation
String s1 = "Hello";            // String literal (pool)
String s2 = new String("Hello"); // New object (heap)

// ⚠️ Comparison
s1 == "Hello"        // true  (same pool object)
s1 == s2              // false (different objects!)
s1.equals(s2)         // true  (same content ✅)
s1.equalsIgnoreCase("HELLO") // true

// Common methods
String name = "  Java Programming  ";
name.length()         // 22
name.trim()           // "Java Programming"
name.strip()          // "Java Programming" (Java 11+ Unicode-aware)
name.toUpperCase()    // "  JAVA PROGRAMMING  "
name.toLowerCase()    // "  java programming  "
name.charAt(2)        // 'J'
name.indexOf("Pro")   // 7
name.contains("Java") // true
name.startsWith("  J")// true
name.endsWith("  ")   // true
name.substring(2, 6)  // "Java"
name.replace("Java", "C++") // "  C++ Programming  "
name.isEmpty()        // false
name.isBlank()        // false (Java 11+)

// Split and join
String csv = "a,b,c,d";
String[] parts = csv.split(",");  // ["a","b","c","d"]
String joined = String.join("-", parts); // "a-b-c-d"

// StringBuilder — mutable, efficient
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 5; i++) {
    sb.append(i).append(", ");
}
String result = sb.toString(); // "0, 1, 2, 3, 4, "

// char[] ↔ String
char[] chars = name.toCharArray();
String back = new String(chars);

// String.format()
String msg = String.format("Name: %s, Age: %d", "Yuvraj", 21);

Performance: Never concatenate strings in a loop with +. Each + creates a new String object → O(n²). Use StringBuilder for O(n) performance.
2.7

Arrays — declaration, multidimensional, Arrays utility class

Fixed-size, indexed data containers

Java arrays are fixed-size, zero-indexed, and type-safe. They hold primitives or objects. Use Arrays utility class for sorting, searching, and filling. For dynamic sizing, use ArrayList (Part 5). Multidimensional arrays are arrays of arrays.

Hindi mein samjhoJava arrays fixed-size, zero-indexed, aur type-safe hain. Primitives ya objects hold karte hain. Sorting, searching ke liye Arrays utility class use karo. Dynamic sizing ke liye ArrayList (Part 5) use karo.
💻 Java — Arrays
// Declaration + initialization
int[] nums = {10, 20, 30, 40, 50};
String[] names = {"Alice", "Bob", "Charlie"};

// Declare then fill
int[] scores = new int[5]; // [0, 0, 0, 0, 0] (defaults)
scores[0] = 95;
scores[1] = 87;

// Access and modify
System.out.println(nums[0]);  // 10 (first element)
System.out.println(nums.length); // 5 (property, not method!)
// nums[5] = 60; // ❌ ArrayIndexOutOfBoundsException!

// Iterate with for-each
for (int n : nums) {
    System.out.print(n + " ");
}

// Iterate with index
for (int i = 0; i < nums.length; i++) {
    System.out.printf("nums[%d] = %d%n", i, nums[i]);
}

// Arrays utility class
import java.util.Arrays;
Arrays.sort(nums);           // Sort in-place: [10,20,30,40,50]
Arrays.fill(scores, 0);      // Fill all with 0
int idx = Arrays.binarySearch(nums, 30); // 2 (must be sorted!)
String str = Arrays.toString(nums);  // "[10, 20, 30, 40, 50]"
boolean eq = Arrays.equals(nums, scores); // false
int[] copy = Arrays.copyOf(nums, 3);     // [10, 20, 30]

// 2D array (matrix)
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
System.out.println(matrix[1][2]); // 6 (row 1, col 2)

// Iterate 2D array
for (int[] row : matrix) {
    for (int val : row) {
        System.out.printf("%3d", val);
    }
    System.out.println();
}

// Jagged array (different row sizes)
int[][] jagged = new int[3][];
jagged[0] = new int[]{1};
jagged[1] = new int[]{1, 2, 3};
jagged[2] = new int[]{1, 2};
