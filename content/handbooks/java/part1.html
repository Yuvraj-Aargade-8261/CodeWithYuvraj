What is Java — history, JDK/JRE/JVM, bytecode, WORA

The world's most popular enterprise language

Java was created by James Gosling at Sun Microsystems in 1995. It's a statically-typed, compiled, object-oriented language. Java's "Write Once, Run Anywhere" (WORA) philosophy means compiled bytecode runs on any platform with a JVM (Java Virtual Machine). Used in enterprise apps, Android, banking, and large-scale systems.

Hindi mein samjhoJava ko James Gosling ne 1995 me Sun Microsystems me banaya tha. Ye statically-typed, compiled, object-oriented language hai. Java ka "Write Once, Run Anywhere" (WORA) matlab hai ki compiled bytecode kisi bhi platform pe JVM ke saath chal sakta hai. Enterprise apps, Android, banking me use hota hai.
💻 Java — Hello World
// Your first Java program
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

// Compile: javac HelloWorld.java
// Run:     java HelloWorld
// Output:  Hello, World!

Java flow: .java (source) → javac → .class (bytecode) → JVM → runs on any OS. This is why Java is platform-independent — the JVM acts as a translator between bytecode and the native OS.

Setup — JDK 17+, IntelliJ IDEA / VS Code, javac & java CLI

Setting up your development environment

Install JDK 17+ (LTS) from adoptium.net or Oracle. Set JAVA_HOME and add bin to PATH. IntelliJ IDEA (Community Edition) is the best Java IDE. VS Code with the "Extension Pack for Java" also works well. Use javac to compile and java to run.

Hindi mein samjhoJDK 17+ (LTS) adoptium.net ya Oracle se install karo. JAVA_HOME set karo aur bin folder PATH me add karo. IntelliJ IDEA (Community Edition) best Java IDE hai. VS Code bhi "Extension Pack for Java" ke saath kaam karta hai.
💻 Terminal — Setup & Compile
# Check Java installation
java --version        # java 17.0.x 2024-xx-xx LTS
javac --version       # javac 17.0.x

# Set JAVA_HOME (Windows)
set JAVA_HOME=C:\Program Files\Java\jdk-17
set PATH=%JAVA_HOME%\bin;%PATH%

# Set JAVA_HOME (macOS/Linux)
export JAVA_HOME=/usr/lib/jvm/java-17
export PATH=$JAVA_HOME/bin:$PATH

# Compile and run
javac HelloWorld.java   # Creates HelloWorld.class
java HelloWorld         # Runs bytecode on JVM

# Single-file execution (Java 11+)
java HelloWorld.java    # Compile + run in one step!

# Run with classpath
java -cp ./out HelloWorld

Variables & data types — 8 primitives, type sizes, ranges

Statically typed — every variable needs a type

Java has 8 primitive types — fixed-size, stack-allocated, high-performance. Unlike Python, you must declare the type before using a variable. Java 10+ supports var for local variable type inference. Every primitive has a corresponding wrapper class for object contexts (collections, generics).

Hindi mein samjhoJava me 8 primitive types hain — fixed-size, stack-allocated, high-performance. Python ke unlike, aapko variable use karne se pehle type declare karna padta hai. Java 10+ me var se local variable type inference milta hai. Har primitive ka ek wrapper class hai.
💻 Java — Variables & Types
// Must declare type!
String name = "Yuvraj";
int age = 21;
double gpa = 9.5;
boolean isStudent = true;
char grade = 'A';

// 8 Primitive types
byte b = 127;              // 1 byte  (-128 to 127)
short s = 32767;           // 2 bytes (-32768 to 32767)
int i = 2_147_483_647;     // 4 bytes (use _ for readability!)
long l = 9_223_372_036_854_775_807L; // 8 bytes (L suffix!)
float f = 3.14f;           // 4 bytes (f suffix!)
double d = 3.14159265358979; // 8 bytes (default decimal)
char c = 'A';              // 2 bytes (Unicode UTF-16)
boolean flag = true;       // 1 bit (true/false only)

// var — type inference (Java 10+)
var message = "Hello";     // Compiler infers String
var count = 42;            // Compiler infers int
var pi = 3.14;             // Compiler infers double

// Constants — use final
final int MAX_SIZE = 100;  // Cannot be reassigned!
final double PI = 3.14159;

// Wrapper classes (for objects/collections)
Integer boxedInt = 42;     // Autoboxing: int → Integer
int unboxed = boxedInt;    // Unboxing: Integer → int

// String is NOT a primitive — it's a class
String str = "Java";       // Immutable object

1.4

Type casting — widening, narrowing, autoboxing, wrapper classes

Converting between types

Widening (implicit) happens automatically when going from smaller to larger type (byte→int→long→double). Narrowing (explicit) requires a cast and may lose data. Autoboxing automatically converts primitives ↔ wrapper objects. Parsing converts strings to numbers.

Hindi mein samjhoWidening (implicit) automatic hota hai jab chhote type se bade type me jata hai (byte→int→long→double). Narrowing (explicit) me cast zaroori hai aur data loss ho sakta hai. Autoboxing primitives ↔ wrapper objects automatically convert karta hai.
💻 Java — Type Casting
// ✅ Widening (implicit) — no data loss
int num = 42;
long big = num;          // int → long (automatic)
double dec = num;        // int → double (automatic)
float f = 10L;           // long → float (automatic)

// ⚠️ Narrowing (explicit) — may lose data!
double pi = 3.14159;
int truncated = (int) pi;  // 3 (decimal lost!)
long bigNum = 100_000L;
short small = (short) bigNum; // May overflow!

// Autoboxing & Unboxing
Integer boxed = 42;      // Autoboxing: int → Integer
int unboxed = boxed;     // Unboxing: Integer → int

// ⚠️ Null unboxing = NullPointerException!
Integer nullBox = null;
// int crash = nullBox;  // ❌ NullPointerException!

// String ↔ Number parsing
int parsed = Integer.parseInt("42");       // String → int
double parsedD = Double.parseDouble("3.14"); // String → double
String str = String.valueOf(42);          // int → String
String str2 = 42 + "";                  // Quick trick: int → String

// char ↔ int (ASCII/Unicode)
char letter = 'A';
int ascii = letter;      // 65
char back = (char) 65;   // 'A'

1.5

Operators — arithmetic, relational, logical, bitwise, ternary

Building expressions

Java has all standard operators. Key differences from Python: / is integer division when both operands are int, && and || are logical operators (not and/or), and instanceof checks types. Java 16+ adds pattern matching for instanceof.

Hindi mein samjhoJava me sab standard operators hain. Python se key differences: / integer division karta hai jab dono operands int hain, && aur || logical operators hain (and/or nahi), aur instanceof type check karta hai.
💻 Java — Operators
// Arithmetic
10 + 3     // 13
10 - 3     // 7
10 * 3     // 30
10 / 3     // 3  ← INTEGER division! (both int)
10.0 / 3   // 3.333... (one is double → double result)
10 % 3     // 1  (modulo)

// No power operator! Use Math.pow()
Math.pow(2, 10)  // 1024.0 (returns double)

// Increment / Decrement
int x = 5;
x++;       // 6 (post-increment)
++x;       // 7 (pre-increment)
x--;       // 6

// Relational
5 == 5     // true (value equality for primitives)
5 != 3     // true
5 > 3      // true
5 >= 5     // true

// ⚠️ For objects, use .equals() not ==
String a = new String("hi");
String b = new String("hi");
a == b        // false (different objects!)
a.equals(b)   // true  (same content ✅)

// Logical (short-circuit)
true && false   // false
true || false   // true
!true           // false

// Ternary (inline if)
int age = 20;
String status = (age >= 18) ? "Adult" : "Minor";

// Bitwise
5 & 3    // 1   (AND)
5 | 3    // 7   (OR)
5 ^ 3    // 6   (XOR)
~5       // -6  (NOT)
1 << 3   // 8   (left shift = ×2³)
8 >> 2   // 2   (right shift = ÷2²)

// instanceof (type checking)
Object obj = "Hello";
if (obj instanceof String s) {  // Pattern matching (16+)
    System.out.println(s.toUpperCase()); // HELLO
}

1.6

Input/Output — System.out, Scanner, printf formatting

Talking to the user

System.out.println() outputs with newline, System.out.print() without. Use Scanner class to read input. printf() provides C-style formatted output with %d, %f, %s placeholders. Java 15+ adds text blocks (""") for multi-line strings.

Hindi mein samjhoSystem.out.println() newline ke saath output deta hai, System.out.print() bina newline. Input ke liye Scanner class use karo. printf() C-style formatted output deta hai %d, %f, %s placeholders ke saath. Java 15+ me text blocks (""") multi-line strings ke liye hain.
💻 Java — I/O & Formatting
import java.util.Scanner;

public class IODemo {
    public static void main(String[] args) {
        // Output methods
        System.out.println("Hello!");      // With newline
        System.out.print("No newline");    // Without newline
        System.out.println();              // Just newline

        // String concatenation
        String name = "Yuvraj";
        int age = 21;
        System.out.println("Name: " + name + ", Age: " + age);

        // printf — formatted output (C-style)
        System.out.printf("Name: %s, Age: %d%n", name, age);
        System.out.printf("Pi: %.2f%n", 3.14159);      // Pi: 3.14
        System.out.printf("Hex: %x%n", 255);             // Hex: ff
        System.out.printf("Padded: %05d%n", 42);         // Padded: 00042
        System.out.printf("Big: %,d%n", 1_000_000);      // Big: 1,000,000
        System.out.printf("Left: %-10s|%n", "hi");       // Left: hi        |

        // Scanner — reading input
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter name: ");
        String input = sc.nextLine();   // Read full line
        System.out.print("Enter age: ");
        int userAge = sc.nextInt();     // Read int
        System.out.print("Enter GPA: ");
        double gpa = sc.nextDouble();   // Read double
        sc.close();                        // Always close Scanner!

        // Text blocks (Java 15+)
        String json = """
                {
                    "name": "Yuvraj",
                    "age": 21
                }
                """;
        System.out.println(json);

        // String.format() — like printf but returns String
        String msg = String.format("Hello %s, age %d", name, age);
    }
}

1.7

Comments, naming conventions, Java coding standards

Writing clean, readable Java code

Java uses // for single-line, /* */ for multi-line, and /** */ for Javadoc comments. Naming follows camelCase for methods/variables, PascalCase for classes, UPPER_SNAKE for constants. Java has strict conventions backed by Google and Oracle style guides.

Hindi mein samjhoJava me // single-line, /* */ multi-line, aur /** */ Javadoc comments ke liye use hota hai. Naming me camelCase methods/variables ke liye, PascalCase classes ke liye, UPPER_SNAKE constants ke liye. Google aur Oracle style guides follow karo.
💻 Java — Comments & Style
// Single-line comment

/*
 * Multi-line comment
 * Used for longer explanations
 */

/**
 * Javadoc comment — generates HTML documentation.
 * Used for classes, methods, and fields.
 *
 * @param radius the radius of the circle
 * @return the calculated area
 * @throws IllegalArgumentException if radius is negative
 */
public static double calculateArea(double radius) {
    if (radius < 0) {
        throw new IllegalArgumentException("Radius must be positive");
    }
    return Math.PI * radius * radius;
}

// ✅ Java naming conventions
int studentAge = 21;            // camelCase for variables
void calculateTotal() {}       // camelCase for methods
class StudentProfile {}        // PascalCase for classes
interface Sortable {}          // PascalCase for interfaces
static final int MAX_SIZE = 100; // UPPER_SNAKE for constants
String getFirstName() {}       // Getters: get + Property
void setFirstName() {}         // Setters: set + Property
boolean isActive() {}          // Boolean getters: is + Adjective

// ❌ Bad naming examples
// int x;          // Too short, meaningless
// int student_age; // Python style, not Java
// class student {} // Should be PascalCase
// int MAX_SIZE;    // Not final? Don't use UPPER_SNAKE
