3.1

Arrays — creation, CRUD, spread operator, Array.from(), Array.of()

The fundamental data container

Arrays are ordered, indexed collections that can hold any type. Create with [] literal (preferred), Array.from() for iterables, or Array.of() for explicit values. Arrays are objects — typeof [] === "object". Check with Array.isArray().

Hindi mein samjhoArrays ordered, indexed collections hain jo kisi bhi type ko hold kar sakte hain. [] literal se banao (best), Array.from() iterables ke liye, Array.of() explicit values ke liye. Arrays objects hain — check karne ke liye Array.isArray() use karo.
💻 JavaScript — Arrays
// ✅ Creating arrays
const fruits = ["apple", "banana", "cherry"];
const mixed = [1, "hello", true, null, { x: 1 }];
const empty = [];

// Array.from() — create from iterables/array-like
Array.from("hello");         // ["h","e","l","l","o"]
Array.from({ length: 5 }, (_, i) => i); // [0,1,2,3,4]
Array.from(new Set([1,2,2,3])); // [1,2,3] (dedupe!)

// Array.of() — explicit values (fixes new Array() quirk)
Array.of(5);       // [5] (not 5 empty slots!)
Array.of(1,2,3);   // [1,2,3]

// ✅ CRUD operations
const arr = [10, 20, 30];

// Read
arr[0];          // 10
arr.at(-1);       // 30 (last element — ES2022)
arr.length;       // 3

// Add
arr.push(40);      // [10,20,30,40] — add to end
arr.unshift(5);    // [5,10,20,30,40] — add to start

// Remove
arr.pop();         // 40 — remove from end
arr.shift();       // 5 — remove from start

// splice — add/remove at any position
arr.splice(1, 1);           // Remove 1 item at index 1
arr.splice(1, 0, 15, 25);  // Insert 15,25 at index 1

// ✅ Checking & searching
Array.isArray([]);         // true
Array.isArray("hello");    // false
fruits.includes("banana"); // true
fruits.indexOf("cherry");  // 2

// ✅ Spread to clone/merge
const clone = [...fruits];
const merged = [...fruits, ...arr];
const withNew = [...fruits, "dragonfruit"];
MethodMutates?ReturnsPurpose
.push()✅ YesNew lengthAdd to end
.pop()✅ YesRemoved itemRemove from end
.unshift()✅ YesNew lengthAdd to start
.shift()✅ YesRemoved itemRemove from start
.splice()✅ YesRemoved itemsAdd/remove at index
[...arr]❌ NoNew arrayShallow copy
3.2

Array methods — map, filter, reduce, find, findIndex, some, every, flat, flatMap

The power methods you'll use daily

These are the non-mutating array methods that return new arrays/values. map transforms, filter selects, reduce accumulates. find/findIndex locate elements. some/every test conditions. flat/flatMap handle nested arrays. These replace 90% of manual loops.

Hindi mein samjhoYe non-mutating array methods hain jo new arrays/values return karte hain. map transform karta hai, filter select karta hai, reduce accumulate karta hai. Ye methods 90% manual loops replace kar dete hain.
💻 JavaScript — Array Methods
const products = [
    { name: "Laptop", price: 999, inStock: true },
    { name: "Phone", price: 699, inStock: true },
    { name: "Tablet", price: 449, inStock: false },
    { name: "Watch", price: 299, inStock: true },
];

// map — transform each element
const names = products.map(p => p.name);
// ["Laptop", "Phone", "Tablet", "Watch"]

const discounted = products.map(p => ({
    ...p, price: p.price * 0.9
}));

// filter — keep matching elements
const available = products.filter(p => p.inStock);
const expensive = products.filter(p => p.price > 500);

// find / findIndex — first match
const phone = products.find(p => p.name === "Phone");
const idx = products.findIndex(p => p.price < 300); // 3

// findLast / findLastIndex (ES2023)
const lastCheap = products.findLast(p => p.price < 500);

// some / every — boolean tests
products.some(p => p.price > 900);  // true (at least one)
products.every(p => p.inStock);     // false (not all)

// reduce — accumulate
const total = products.reduce((sum, p) => sum + p.price, 0);
// 2446

// reduce to group by category
const grouped = products.reduce((acc, p) => {
    const key = p.inStock ? "available" : "out";
    (acc[key] ??= []).push(p);
    return acc;
}, {});

// flat — flatten nested arrays
[1, [2, [3, [4]]]].flat();      // [1, 2, [3, [4]]] (1 level)
[1, [2, [3, [4]]]].flat(Infinity); // [1, 2, 3, 4]

// flatMap — map + flat(1) in one step
const sentences = ["hello world", "foo bar"];
sentences.flatMap(s => s.split(" "));
// ["hello", "world", "foo", "bar"]

// ✅ Chain everything!
const result = products
    .filter(p => p.inStock)
    .map(p => ({ ...p, tax: p.price * 0.18 }))
    .reduce((sum, p) => sum + p.price + p.tax, 0);
3.3

Sorting & iteration — sort(), toSorted(), reverse(), entries, at()

Ordering and traversing

sort() mutates the original array and sorts as strings by default (trap!). Always pass a compare function. ES2023 adds toSorted(), toReversed(), toSpliced() — non-mutating copies. with(index, value) replaces at index without mutation.

Hindi mein samjhosort() original array ko mutate karta hai aur default me strings jaisa sort karta hai (trap!). Hamesha compare function do. ES2023 me toSorted(), toReversed() aaye — ye non-mutating copies banate hain.
💻 JavaScript — Sorting & Iteration
// ⚠️ sort() mutates AND sorts as strings!
const nums = [10, 1, 21, 2];
nums.sort();  // [1, 10, 2, 21] ← WRONG! (string comparison)

// ✅ Always use compare function
nums.sort((a, b) => a - b); // [1, 2, 10, 21] ascending
nums.sort((a, b) => b - a); // [21, 10, 2, 1] descending

// Sort strings properly
const words = ["banana", "Apple", "cherry"];
words.sort((a, b) => a.localeCompare(b)); // Case-insensitive

// Sort objects by property
const users = [
    { name: "Charlie", age: 30 },
    { name: "Alice", age: 25 },
    { name: "Bob", age: 35 }
];
users.sort((a, b) => a.age - b.age); // By age ascending
users.sort((a, b) => a.name.localeCompare(b.name)); // By name

// ✅ ES2023 — Non-mutating methods
const original = [3, 1, 4, 1, 5];
const sorted = original.toSorted((a, b) => a - b);
// sorted: [1, 1, 3, 4, 5] — original unchanged!

const reversed = original.toReversed();
// reversed: [5, 1, 4, 1, 3] — original unchanged!

const spliced = original.toSpliced(1, 2, 99);
// spliced: [3, 99, 1, 5] — original unchanged!

const replaced = original.with(2, 99);
// replaced: [3, 1, 99, 1, 5] — original unchanged!

// .at() — ES2022 (supports negative indices!)
original.at(0);   // 3 (first)
original.at(-1);  // 5 (last)
original.at(-2);  // 1 (second-to-last)
MethodMutates?ES VersionPurpose
.sort()✅ YesES1Sort in-place
.reverse()✅ YesES1Reverse in-place
.toSorted()❌ NoES2023Sort → new array
.toReversed()❌ NoES2023Reverse → new array
.toSpliced()❌ NoES2023Splice → new array
.with(i, v)❌ NoES2023Replace at index
.at(i)❌ NoES2022Access by index (neg ok)
Modern JS: Always prefer toSorted()/toReversed() over sort()/reverse() when you don't want to mutate. This prevents subtle bugs in React state and functional code.
3.4

Objects — creation, properties, computed keys, Object methods

Everything is an object

Objects are key-value collections. Keys are strings (or Symbols). Use dot notation for known keys, bracket notation for dynamic keys. Shorthand properties and computed keys make objects concise. Object.keys(), .values(), .entries() convert to arrays for iteration.

Hindi mein samjhoObjects key-value collections hain. Keys strings (ya Symbols) hain. Dot notation known keys ke liye, bracket notation dynamic keys ke liye. Object.keys(), .values(), .entries() se arrays me convert karke iterate kar sakte ho.
💻 JavaScript — Objects
// Object literal
const user = {
    name: "Alice",
    age: 25,
    "full-name": "Alice Smith", // Needs quotes (has dash)
    greet() { return `Hi, I'm ${this.name}`; }
};

// Access
user.name;              // "Alice" (dot)
user["full-name"];      // "Alice Smith" (bracket)
const key = "age";
user[key];              // 25 (dynamic)

// ✅ Shorthand properties
const name = "Bob", age = 30;
const bob = { name, age }; // { name: "Bob", age: 30 }

// ✅ Computed property keys
const field = "email";
const obj = { [field]: "a@b.com", [`${field}_verified`]: true };

// ✅ Object methods
Object.keys(user);      // ["name", "age", "full-name", "greet"]
Object.values(user);    // ["Alice", 25, "Alice Smith", ƒ]
Object.entries(user);   // [["name","Alice"], ["age",25], ...]
Object.fromEntries([["a",1],["b",2]]); // {a:1, b:2}

// Check properties
"name" in user;          // true
user.hasOwnProperty("age"); // true
Object.hasOwn(user, "age"); // true (modern)

// ✅ Object.assign / spread copy
const copy1 = Object.assign({}, user, { age: 26 });
const copy2 = { ...user, age: 26 }; // Preferred!

// Freeze & seal
const config = Object.freeze({ port: 3000 });
// config.port = 4000; // ❌ Silently fails (strict: throws)

// Iterate objects
for (const [k, v] of Object.entries(user)) {
    console.log(`${k}: ${v}`);
}
3.5

Destructuring — array, object, nested, defaults, rest pattern

Unpack values elegantly

Destructuring extracts values from arrays/objects into variables. Supports defaults, renaming, nesting, and rest pattern. Used everywhere in React (const {useState} = React), API responses, and function parameters.

Hindi mein samjhoDestructuring arrays/objects se values ko variables me extract karta hai. Defaults, renaming, nesting aur rest pattern support karta hai. React me har jagah use hota hai.
💻 JavaScript — Destructuring
// ✅ Array destructuring
const [a, b, c] = [1, 2, 3];
const [first, , third] = [10, 20, 30]; // Skip elements
const [x = 0, y = 0] = [5]; // Defaults: x=5, y=0

// Swap variables
let p = 1, q = 2;
[p, q] = [q, p]; // p=2, q=1

// ✅ Object destructuring
const user = { name: "Alice", age: 25, city: "Mumbai" };
const { name, age } = user;
const { name: userName, age: userAge } = user; // Rename
const { role = "viewer" } = user; // Default

// ✅ Nested destructuring
const data = {
    user: { name: "Bob", address: { city: "Delhi", zip: "110001" } }
};
const { user: { address: { city } } } = data; // "Delhi"

// ✅ Rest pattern
const { name: n, ...rest } = user;
// n = "Alice", rest = { age: 25, city: "Mumbai" }

const [head, ...tail] = [1, 2, 3, 4];
// head = 1, tail = [2, 3, 4]

// ✅ In function parameters (very common!)
function createUser({ name, age, role = "viewer" }) {
    return { name, age, role };
}
createUser({ name: "Charlie", age: 30 });

// Array destructuring in params
const points = [[1,2], [3,4], [5,6]];
points.forEach(([x, y]) => console.log(x, y));
3.6

Spread & Rest — arrays/objects, shallow copy, immutable updates

Three dots, two meanings

... is spread when expanding (arrays/objects into elements) and rest when collecting (function params, destructuring). Spread creates shallow copies — nested objects are still references! Use structuredClone() for deep copies.

Hindi mein samjho... spread hai jab expand karta hai aur rest hai jab collect karta hai. Spread shallow copies banata hai — nested objects references hain! Deep copy ke liye structuredClone() use karo.
💻 JavaScript — Spread & Rest
// ✅ Spread in arrays
const a = [1, 2], b = [3, 4];
const merged = [...a, ...b];          // [1,2,3,4]
const withItem = [...a, 99, ...b];    // [1,2,99,3,4]
const clone = [...a];                  // Shallow copy

// ✅ Spread in objects
const defaults = { theme: "dark", lang: "en" };
const user = { name: "Alice", theme: "light" };
const config = { ...defaults, ...user };
// { theme: "light", lang: "en", name: "Alice" }
// Later spread wins! (theme overridden)

// Immutable update pattern (React standard)
const state = { count: 0, items: ["a"] };
const next = { ...state, count: state.count + 1 };
const withItem2 = { ...state, items: [...state.items, "b"] };

// ⚠️ Shallow copy trap
const original = { user: { name: "Alice" } };
const shallow = { ...original };
shallow.user.name = "Bob"; // ⚠️ Also changes original!

// ✅ Deep copy — structuredClone (modern)
const deep = structuredClone(original);
deep.user.name = "Charlie"; // ✅ Original unchanged

// ✅ Rest in functions
function log(level, ...messages) {
    console.log(`[${level}]`, ...messages);
}
log("INFO", "Server", "started", "on port", 3000);
3.7

JSON — parse, stringify, structuredClone, reviver/replacer

The universal data format

JSON (JavaScript Object Notation) is the standard for API data exchange. JSON.parse() converts string → object. JSON.stringify() converts object → string. reviver and replacer functions customize conversion. structuredClone() is the modern deep-clone solution.

Hindi mein samjhoJSON API data exchange ka standard hai. JSON.parse() string → object convert karta hai. JSON.stringify() object → string convert karta hai. structuredClone() modern deep-clone solution hai.
💻 JavaScript — JSON
// JSON.parse — string → object
const json = '{"name":"Alice","age":25}';
const user = JSON.parse(json);

// JSON.stringify — object → string
const str = JSON.stringify(user);
const pretty = JSON.stringify(user, null, 2); // Formatted

// Replacer — filter/transform during stringify
JSON.stringify(user, ["name"]); // '{"name":"Alice"}' (only name)
JSON.stringify(user, (key, val) =>
    key === "age" ? undefined : val
); // Exclude age

// Reviver — transform during parse
const data = '{"date":"2024-01-15"}';
JSON.parse(data, (key, val) =>
    key === "date" ? new Date(val) : val
);

// ⚠️ JSON limitations
// Cannot serialize: functions, undefined, Symbol, Map, Set, Date
JSON.stringify({ fn: () => {} }); // '{}' (fn dropped!)
JSON.stringify({ d: new Date() }); // Date → string

// ✅ Deep clone methods
// 1. structuredClone (best — handles Map, Set, Date)
const deep = structuredClone({ nested: { a: 1 } });

// 2. JSON trick (old — loses functions, Date, etc.)
const jsonClone = JSON.parse(JSON.stringify(obj));

// ✅ API data handling pattern
async function fetchUsers() {
    const res = await fetch("/api/users");
    const data = await res.json(); // Auto JSON.parse
    return data;
}
