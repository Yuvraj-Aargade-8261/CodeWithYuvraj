1.1

What is JavaScript — history, ECMAScript, browser vs Node.js

The language of the web

JavaScript was created in 1995 by Brendan Eich at Netscape in just 10 days. Despite its name, it has no relation to Java. ECMAScript (ES) is the standard — JS is the implementation. ES6 (2015) was the biggest update ever. Today JS runs everywhere: browsers (V8 in Chrome), servers (Node.js), mobile (React Native), desktop (Electron), and even IoT.

Hindi mein samjhoJavaScript 1995 me Brendan Eich ne sirf 10 din me banaya tha. Java se koi relation nahi hai. ECMAScript (ES) standard hai — JS uska implementation hai. ES6 (2015) sabse bada update tha. Aaj JS har jagah chalta hai: browsers, servers (Node.js), mobile aur desktop.
💻 JavaScript — Your First Program
// JavaScript runs in the browser console or Node.js
console.log("Hello, World!");  // Output to console

// JavaScript is dynamically typed
let name = "Yuvraj";    // String
let age = 20;            // Number
let isStudent = true;   // Boolean

console.log(`Hi, I'm ${name} and I'm ${age} years old`);

// Check your JS engine version
console.log(typeof "hello"); // "string"
console.log(typeof 42);      // "number"
console.log(typeof true);    // "boolean"

Setup — DevTools, VS Code, Node.js, script tag, defer/async

Setting up your environment

You need a browser (Chrome DevTools) + editor (VS Code) + optionally Node.js for running JS outside the browser. Use <script> tag to include JS in HTML. defer loads after HTML parsing, async loads independently. Always use defer for regular scripts.

Hindi mein samjhoAapko browser (Chrome DevTools) + editor (VS Code) + optionally Node.js chahiye. <script> tag se JS HTML me include hoti hai. defer HTML parse hone ke baad load karta hai — hamesha defer use karo.
💻 HTML — Including JavaScript
<!-- ❌ Old way — blocks HTML parsing -->
<script src="app.js"></script>

<!-- ✅ defer — loads after HTML is parsed (RECOMMENDED) -->
<script src="app.js" defer></script>

<!-- async — loads independently, executes ASAP -->
<script src="analytics.js" async></script>

<!-- ES Module — automatically deferred -->
<script type="module" src="app.js"></script>

<!-- Inline JS -->
<script>
  console.log("Inline JS!");
</script>
💻 Terminal — Node.js Setup
# Check Node.js version
node --version       # v20.x or higher
npm --version        # 10.x or higher

# Run a JS file
node app.js

# Interactive REPL
node                 # Type JS expressions directly
> 2 + 3              // 5
> "hello".toUpperCase() // "HELLO"
> .exit              // Exit REPL

1.3

Variables — var vs let vs const, hoisting, TDZ, block scope

Declaring variables the modern way

var is function-scoped and hoisted (legacy — avoid). let is block-scoped and reassignable. const is block-scoped and cannot be reassigned (but objects/arrays inside can be mutated). Default to const, use let only when you need to reassign. Never use var in modern JS.

Hindi mein samjhovar function-scoped hai aur hoisted hota hai (legacy — avoid karo). let block-scoped hai aur reassign ho sakta hai. const block-scoped hai aur reassign nahi ho sakta. Default me const use karo, sirf let jab reassign karna ho.
💻 JavaScript — var vs let vs const
// ❌ var — function-scoped, hoisted (AVOID!)
console.log(x); // undefined (hoisted!)
var x = 10;

if (true) {
    var leaked = "I leak out!";
}
console.log(leaked); // "I leak out!" — var ignores block scope!

// ✅ let — block-scoped, reassignable
let count = 0;
count = 1;        // ✅ Can reassign
count = 2;        // ✅ Can reassign again

if (true) {
    let inner = "block scoped";
}
// console.log(inner); // ❌ ReferenceError — not accessible!

// ✅ const — block-scoped, NOT reassignable
const PI = 3.14159;
// PI = 3.14; // ❌ TypeError: Assignment to constant

// ⚠️ const with objects — reference is constant, content is NOT
const user = { name: "Alice", age: 25 };
user.age = 26;     // ✅ Mutating property is allowed!
// user = {};       // ❌ Cannot reassign the reference

const nums = [1, 2, 3];
nums.push(4);      // ✅ [1, 2, 3, 4] — array content can change
// nums = [];       // ❌ Cannot reassign

// TDZ (Temporal Dead Zone) — let/const before declaration
// console.log(y);  // ❌ ReferenceError (TDZ!)
let y = 42;
console.log(y);    // ✅ 42

// Scope comparison
for (var i = 0; i < 3; i++) {} console.log(i); // 3 — var leaks!
for (let j = 0; j < 3; j++) {}
// console.log(j); // ❌ ReferenceError — let stays in block

Golden rule: Always use const by default. Switch to let only when you need to reassign. Never use var — it causes bugs with scope leaking and hoisting.
1.4

Data types — primitives, typeof, null vs undefined, BigInt, Symbol

JavaScript's 7 primitive types + objects

JavaScript has 7 primitive types: string, number, bigint, boolean, undefined, null, symbol — and object (reference type). Primitives are immutable and copied by value. Objects are copied by reference. typeof returns a string representing the type — but beware: typeof null === "object" is a famous bug!

Hindi mein samjhoJavaScript me 7 primitive types hain: string, number, bigint, boolean, undefined, null, symbol — aur object (reference type). Primitives immutable hain aur value se copy hote hain. Objects reference se copy hote hain. typeof null === "object" ek famous bug hai!
💻 JavaScript — Data Types
// ✅ 7 Primitive Types
const str = "Hello";           // string
const num = 42;                // number (64-bit float)
const big = 9007199254740993n; // bigint (arbitrary precision)
const bool = true;             // boolean
const undef = undefined;       // undefined (not assigned)
const nul = null;              // null (intentional empty)
const sym = Symbol("id");     // symbol (unique identifier)

// Object (reference type)
const obj = { name: "Alice" };
const arr = [1, 2, 3];          // Array is an object!
const fn = () => {};           // Function is an object!

// typeof operator
typeof "hello"    // "string"
typeof 42         // "number"
typeof 42n        // "bigint"
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object" — ⚠️ FAMOUS BUG! (since 1995)
typeof Symbol()   // "symbol"
typeof {}         // "object"
typeof []         // "object" — arrays are objects!
typeof function(){} // "function" — special case

// ✅ Number quirks
console.log(0.1 + 0.2);          // 0.30000000000000004 ⚠️
console.log(0.1 + 0.2 === 0.3);  // false! IEEE 754 floating point
console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
console.log(Number.isNaN(NaN));      // true
console.log(Number.isFinite(Infinity)); // false

// null vs undefined
let a;              // undefined — declared but not assigned
let b = null;       // null — intentionally empty
console.log(a == b);  // true (loose equality)
console.log(a === b); // false (strict equality)

// BigInt — for numbers beyond MAX_SAFE_INTEGER
const huge = 123456789012345678901234567890n;
console.log(huge + 1n); // 123456789012345678901234567891n
// huge + 1; // ❌ TypeError: Cannot mix BigInt and Number

1.5

Type coercion — implicit vs explicit, truthy/falsy, == vs ===

JavaScript's type magic (and traps)

Type coercion is JS auto-converting types. Implicit: "5" + 3 = "53" (string wins). Explicit: Number("5") = 5. Use === (strict equality — no coercion) instead of == (loose — coerces). Know the 8 falsy values: false, 0, -0, 0n, "", null, undefined, NaN. Everything else is truthy.

Hindi mein samjhoType coercion me JS automatically types convert karta hai. "5" + 3 = "53" (string jeet jaata hai). Hamesha === use karo (== nahi). 8 falsy values yaad rakho: false, 0, -0, 0n, "", null, undefined, NaN.
💻 JavaScript — Type Coercion
// ✅ Implicit coercion — JS converts automatically
"5" + 3       // "53" — number → string (+ concatenates)
"5" - 3       // 2 — string → number (- is math only)
"5" * 2       // 10 — string → number
true + 1      // 2 — true becomes 1
false + 1     // 1 — false becomes 0
"" + 0        // "0" — number → string
null + 1      // 1 — null becomes 0
undefined + 1 // NaN — undefined can't convert

// ✅ Explicit coercion — you convert manually
Number("42")      // 42
Number("")        // 0
Number(true)      // 1
Number(null)      // 0
Number(undefined) // NaN
Number("hello")   // NaN

String(42)        // "42"
String(null)      // "null"
String(undefined) // "undefined"

Boolean(0)        // false
Boolean("")       // false
Boolean("hello")  // true
Boolean([])       // true — empty array is truthy!
Boolean({})       // true — empty object is truthy!

// ✅ == vs === (ALWAYS use ===)
5 == "5"        // true ❌ (coerces!)
5 === "5"       // false ✅ (no coercion)
null == undefined  // true ❌
null === undefined // false ✅
0 == false      // true ❌
0 === false     // false ✅
"" == false     // true ❌
"" === false    // false ✅

// ✅ Truthy / Falsy in conditions
const name = "";
if (name) { /* skipped — "" is falsy */ }

const list = [];
if (list) { /* runs — [] is truthy! Check .length instead */ }
if (list.length) { /* skipped — 0 is falsy */ }

// Double-bang (!!) — convert to boolean
!!"hello"  // true
!!0        // false
!!null     // false
!![]      // true (empty array is truthy!)

Rule: Always use === and !==. Never use == — it silently coerces types and causes subtle bugs. The only exception: value == null checks both null and undefined (acceptable shorthand).
1.6

Operators — arithmetic, comparison, logical, nullish coalescing, optional chaining

All the operators you need

JavaScript has standard arithmetic, comparison, and logical operators. Modern additions: Nullish coalescing (??) returns the right side only if left is null/undefined (not falsy). Optional chaining (?.) safely accesses nested properties without throwing if something is null/undefined.

Hindi mein samjhoJavaScript me standard arithmetic, comparison aur logical operators hain. Modern additions: ?? sirf null/undefined pe right side return karta hai. ?. safely nested properties access karta hai bina error ke.
💻 JavaScript — Operators
// Arithmetic
10 + 3   // 13 (addition)
10 - 3   // 7 (subtraction)
10 * 3   // 30 (multiplication)
10 / 3   // 3.3333... (division — always float!)
10 % 3   // 1 (remainder)
2 ** 10  // 1024 (exponentiation)

// Increment / Decrement
let x = 5;
x++;  // 5 (returns then increments)
++x;  // 7 (increments then returns)

// Comparison (always use === and !==)
5 === 5    // true (strict equal)
5 !== "5"  // true (strict not equal)
5 > 3      // true
5 >= 5     // true

// Logical
true && false  // false (AND)
true || false  // true (OR)
!true          // false (NOT)

// Short-circuit — && and || return values, not booleans!
"hello" && 42     // 42 (both truthy → returns last)
"" && 42          // "" (first falsy → returns it)
null || "default" // "default" (first falsy → try next)
"value" || "def" // "value" (first truthy → returns it)

// ✅ Nullish Coalescing (??) — ES2020
// Returns right side ONLY if left is null/undefined
const a = null ?? "fallback";    // "fallback"
const b = undefined ?? "fallback"; // "fallback"
const c = 0 ?? "fallback";       // 0 ← preserves falsy!
const d = "" ?? "fallback";      // "" ← preserves falsy!
// Compare with ||
const e = 0 || "fallback";       // "fallback" ← 0 is falsy!

// ✅ Optional Chaining (?.) — ES2020
const user = { address: { city: "Mumbai" } };
user.address.city         // "Mumbai"
user.phone?.number        // undefined (no error!)
user.getAge?.()           // undefined (safe method call)
user.friends?.[0]         // undefined (safe array access)

// Without ?. — would throw!
// user.phone.number // ❌ TypeError: Cannot read property of undefined

// ✅ Logical Assignment (ES2021)
let val = null;
val ??= "default";  // val = "default" (only if null/undefined)
val ||= "backup";  // val stays "default" (already truthy)
val &&= "updated"; // val = "updated" (because truthy)

1.7

I/O — console methods, template literals, string methods

Output, debugging, and string power

console has many methods beyond .log(): .table(), .time(), .group(), .error(). Template literals (`backticks`) support interpolation (${expr}), multi-line strings, and tagged templates. Master the essential string methods: includes(), startsWith(), slice(), split(), trim(), replace(), padStart().

Hindi mein samjhoconsole me .log() ke alawa bhi bahut methods hain: .table(), .time(), .error(). Template literals (`backticks`) me ${expr} se interpolation hoti hai. String methods daily use hote hain.
💻 JavaScript — Console & Template Literals
// Console methods
console.log("Standard output");
console.error("❌ Error message");  // Red in DevTools
console.warn("⚠️ Warning");         // Yellow
console.info("ℹ️ Info");             // Blue

// console.table — beautiful for arrays/objects!
console.table([
    { name: "Alice", age: 25 },
    { name: "Bob", age: 30 }
]);

// console.time — measure performance
console.time("loop");
for (let i = 0; i < 1000000; i++) {}
console.timeEnd("loop"); // loop: 2.5ms

// console.group — organize output
console.group("User Info");
console.log("Name: Alice");
console.log("Age: 25");
console.groupEnd();

// ✅ Template Literals (backticks)
const name = "Yuvraj", age = 20;
console.log(`Hello, ${name}! You are ${age} years old.`);
console.log(`2 + 3 = ${2 + 3}`); // "2 + 3 = 5"

// Multi-line strings
const html = `
  <div class="card">
    <h2>${name}</h2>
    <p>Age: ${age}</p>
  </div>
`;

// ✅ Essential String Methods
const str = "  Hello, World!  ";
str.length          // 17
str.trim()          // "Hello, World!"
str.toUpperCase()   // "  HELLO, WORLD!  "
str.toLowerCase()   // "  hello, world!  "
str.includes("World")   // true
str.startsWith("  He")  // true
str.endsWith("!  ")     // true
str.indexOf("World")    // 9
str.slice(2, 7)        // "Hello"
str.replace("World", "JS") // "  Hello, JS!  "
str.split(", ")        // ["  Hello", "World!  "]
"42".padStart(5, "0")  // "00042"
"hi".repeat(3)         // "hihihi"
str.at(-1)              // " " (last character)
str.replaceAll(" ", "") // "Hello,World!"
