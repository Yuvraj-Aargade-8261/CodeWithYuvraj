6.1

DOM Selectors — querySelector, querySelectorAll, traversal

Finding elements

querySelector() returns the first match. querySelectorAll() returns a NodeList (not a live HTMLCollection!). Use CSS selectors. Traversal: parentElement, children, nextElementSibling, closest(). Avoid getElementById — querySelector does everything.

Hindi mein samjhoquerySelector() pehla match return karta hai. querySelectorAll() NodeList return karta hai. CSS selectors use karo. closest() parent direction me search karta hai.
💻 JavaScript — DOM Selectors
// ✅ querySelector — first match
const header = document.querySelector("h1");
const btn = document.querySelector(".btn-primary");
const nav = document.querySelector("#main-nav");
const item = document.querySelector("[data-id='42']");

// querySelectorAll — all matches (NodeList)
const cards = document.querySelectorAll(".card");
cards.forEach(card => console.log(card.textContent));
// Convert to array for full array methods
[...cards].filter(c => c.classList.contains("active"));

// ✅ Traversal
const el = document.querySelector(".item");
el.parentElement;           // Direct parent
el.children;                // Child elements (HTMLCollection)
el.firstElementChild;       // First child element
el.lastElementChild;        // Last child element
el.nextElementSibling;      // Next sibling element
el.previousElementSibling;  // Previous sibling

// closest() — find nearest ancestor matching selector
const card = btn.closest(".card"); // Find parent .card

// matches() — test if element matches selector
el.matches(".active"); // true/false
6.2

DOM Manipulation — create, modify, remove, classList, attributes, styles

Changing the page dynamically

createElement() + append() adds elements. textContent for text (safe), innerHTML for HTML (XSS risk!). classList manages CSS classes. dataset accesses data-* attributes. Use insertAdjacentHTML() for fast HTML insertion.

Hindi mein samjhocreateElement() + append() se elements add karo. textContent text ke liye (safe), innerHTML HTML ke liye (XSS risk!). classList se CSS classes manage karo.
💻 JavaScript — DOM Manipulation
// ✅ Create and append elements
const div = document.createElement("div");
div.textContent = "Hello!";
div.className = "card";
document.body.append(div);

// Multiple elements at once
const fragment = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
    const li = document.createElement("li");
    li.textContent = `Item ${i}`;
    fragment.append(li);
}
document.querySelector("ul").append(fragment); // Single reflow!

// ✅ classList — manage classes
el.classList.add("active", "visible");
el.classList.remove("hidden");
el.classList.toggle("dark-mode");
el.classList.replace("old", "new");
el.classList.contains("active"); // true

// ✅ Attributes & data attributes
el.setAttribute("aria-label", "Close");
el.getAttribute("href");
el.removeAttribute("disabled");
el.dataset.userId = "42";   // Sets data-user-id="42"
el.dataset.userId;           // "42"

// ✅ Styles
el.style.color = "red";
el.style.backgroundColor = "#000"; // camelCase!
// Better: use classes instead of inline styles
getComputedStyle(el).fontSize; // Read computed style

// ✅ Remove elements
el.remove();                    // Remove self
parent.removeChild(child);      // Remove child
el.replaceWith(newEl);          // Replace

// insertAdjacentHTML — fast insertion
el.insertAdjacentHTML("beforeend", `<span>Hi</span>`);
// Positions: beforebegin, afterbegin, beforeend, afterend
6.3

Events — addEventListener, event object, bubbling, delegation

Making things interactive

addEventListener() attaches handlers. The event object has target, currentTarget, type, preventDefault(). Events bubble up from child to parent. Event delegation attaches ONE handler to a parent instead of many to children — essential for dynamic content.

Hindi mein samjhoaddEventListener() handlers attach karta hai. Events child se parent tak bubble karte hain. Event delegation me parent pe ek handler laga ke sab children handle karte hain — dynamic content ke liye essential.
💻 JavaScript — Events
// ✅ addEventListener
const btn = document.querySelector("#myBtn");
btn.addEventListener("click", (e) => {
    console.log(e.target);        // Element clicked
    console.log(e.currentTarget); // Element handler is on
    console.log(e.type);          // "click"
});

// Remove listener (needs reference!)
const handler = () => console.log("clicked");
btn.addEventListener("click", handler);
btn.removeEventListener("click", handler);

// Options
btn.addEventListener("click", handler, { once: true }); // Fire once
btn.addEventListener("scroll", handler, { passive: true }); // Performance

// preventDefault — stop default behavior
document.querySelector("form").addEventListener("submit", (e) => {
    e.preventDefault(); // Stop form submission
    // Handle with JS instead
});

// ✅ Event Delegation — ONE handler for many elements
document.querySelector(".todo-list").addEventListener("click", (e) => {
    const item = e.target.closest(".todo-item");
    if (!item) return; // Clicked outside item

    if (e.target.matches(".delete-btn")) {
        item.remove();
    } else if (e.target.matches(".toggle")) {
        item.classList.toggle("done");
    }
});
// Works even for dynamically added items!

// stopPropagation — stop bubbling
inner.addEventListener("click", (e) => {
    e.stopPropagation(); // Parent won't receive this
});
Always use event delegation for lists, tables, and dynamic content. It's more performant (one handler vs hundreds) and automatically works for new elements.
6.4

Advanced Events — keyboard, mouse, touch, custom events, IntersectionObserver

Beyond click handlers

Keyboard events: keydown/keyup with e.key. Mouse: mouseenter/mouseleave (no bubbling). Custom events: new CustomEvent() with detail data. IntersectionObserver detects visibility — replaces scroll-based lazy loading.

Hindi mein samjhoKeyboard events: keydown/keyup me e.key use karo. Custom events: new CustomEvent() se apne events banao. IntersectionObserver element visibility detect karta hai — lazy loading ke liye use karo.
💻 JavaScript — Advanced Events
// Keyboard events
document.addEventListener("keydown", (e) => {
    if (e.key === "Escape") closeModal();
    if (e.ctrlKey && e.key === "s") { e.preventDefault(); save(); }
});

// ✅ Custom Events — component communication
const event = new CustomEvent("user-login", {
    detail: { userId: 42, name: "Alice" },
    bubbles: true
});
document.dispatchEvent(event);
document.addEventListener("user-login", (e) => {
    console.log(e.detail.name); // "Alice"
});

// ✅ IntersectionObserver — lazy loading, animations
const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            entry.target.classList.add("visible");
            const img = entry.target;
            img.src = img.dataset.src; // Lazy load!
            observer.unobserve(img);
        }
    });
}, { threshold: 0.1 });

document.querySelectorAll("img[data-src]")
    .forEach(img => observer.observe(img));
6.5

Forms — FormData, validation, submit handling, input events

Professional form handling

FormData extracts all form values instantly. Use input/change events for real-time validation. The Constraint Validation API (checkValidity(), setCustomValidity()) provides native validation without libraries.

Hindi mein samjhoFormData se sab form values instantly mil jaati hain. input/change events se real-time validation karo. Constraint Validation API se native validation bina library ke ho jaata hai.
💻 JavaScript — Form Handling
// ✅ FormData — extract all values
const form = document.querySelector("#signup");
form.addEventListener("submit", async (e) => {
    e.preventDefault();
    const data = new FormData(form);
    const obj = Object.fromEntries(data);
    // { name: "Alice", email: "a@b.com", age: "25" }

    await fetch("/api/signup", {
        method: "POST",
        body: JSON.stringify(obj),
        headers: { "Content-Type": "application/json" }
    });
});

// ✅ Real-time validation
const emailInput = document.querySelector("#email");
emailInput.addEventListener("input", (e) => {
    const valid = /^[\w.-]+@[\w.-]+\.\w{2,}$/.test(e.target.value);
    e.target.setCustomValidity(valid ? "" : "Invalid email");
    e.target.reportValidity();
});

// checkValidity before submit
if (form.checkValidity()) { /* submit */ }
6.6

Storage — localStorage, sessionStorage, cookies, IndexedDB basics

Persisting data client-side

localStorage persists across sessions (5-10MB). sessionStorage clears on tab close. Both store strings only — use JSON.stringify/parse. Cookies are for server communication. IndexedDB handles large structured data.

Hindi mein samjholocalStorage sessions ke across persist karta hai. sessionStorage tab close pe clear ho jaata hai. Dono sirf strings store karte hain — JSON.stringify/parse use karo.
💻 JavaScript — Web Storage
// ✅ localStorage — persists forever (until cleared)
localStorage.setItem("theme", "dark");
localStorage.getItem("theme"); // "dark"
localStorage.removeItem("theme");
localStorage.clear(); // Remove ALL

// Store objects — must serialize!
const user = { name: "Alice", prefs: { theme: "dark" } };
localStorage.setItem("user", JSON.stringify(user));
const loaded = JSON.parse(localStorage.getItem("user"));

// ✅ Reusable storage helper
const storage = {
    get(key, fallback = null) {
        try { return JSON.parse(localStorage.getItem(key)) ?? fallback; }
        catch { return fallback; }
    },
    set(key, value) { localStorage.setItem(key, JSON.stringify(value)); },
    remove(key) { localStorage.removeItem(key); }
};

// Listen for storage changes (cross-tab!)
window.addEventListener("storage", (e) => {
    console.log(`${e.key} changed from ${e.oldValue} to ${e.newValue}`);
});
6.7

Web APIs — clipboard, geolocation, notifications, history, URL

Browser superpowers

Modern browsers expose powerful APIs: Clipboard for copy/paste, Geolocation for location, Notifications for alerts, History API for SPA routing, URL/URLSearchParams for query strings. Most require HTTPS and user permission.

Hindi mein samjhoModern browsers powerful APIs dete hain: Clipboard copy/paste ke liye, History API SPA routing ke liye, URL query strings ke liye. Zyaadatar HTTPS aur user permission chahiye.
💻 JavaScript — Web APIs
// ✅ Clipboard API
await navigator.clipboard.writeText("Copied!");
const text = await navigator.clipboard.readText();

// ✅ URL & URLSearchParams
const url = new URL("https://example.com/search?q=js&page=2");
url.searchParams.get("q");      // "js"
url.searchParams.set("page", 3);
url.searchParams.append("sort", "date");
url.toString(); // Full URL with updated params

// ✅ History API — SPA routing
history.pushState({ page: 2 }, "", "/products?page=2");
window.addEventListener("popstate", (e) => {
    console.log(e.state); // Navigate to state
});

// ✅ ResizeObserver — responsive JS
const ro = new ResizeObserver(entries => {
    for (const entry of entries) {
        const { width } = entry.contentRect;
        entry.target.classList.toggle("compact", width < 400);
    }
});
ro.observe(document.querySelector(".container"));

Drag & Drop API

HTML5 Drag & Drop enables native drag interactions. Set draggable="true" on elements. Listen for dragstart, dragover (must preventDefault!), and drop. Use dataTransfer to pass data between drag source and drop target.

Hindi mein samjhoHTML5 Drag & Drop native drag interactions enable karta hai. Elements pe draggable="true" lagao. dragstart, dragover (preventDefault zaroori!), aur drop events suno. dataTransfer se data pass karo.
💻 JavaScript — Drag & Drop
// ✅ Make element draggable
// HTML: <div draggable="true" data-id="42">Drag me</div>

const draggable = document.querySelector("[draggable]");
draggable.addEventListener("dragstart", (e) => {
    e.dataTransfer.setData("text/plain", e.target.dataset.id);
    e.target.classList.add("dragging");
});
draggable.addEventListener("dragend", (e) => {
    e.target.classList.remove("dragging");
});

// ✅ Drop zone
const dropZone = document.querySelector(".drop-zone");
dropZone.addEventListener("dragover", (e) => {
    e.preventDefault(); // REQUIRED to allow drop!
    dropZone.classList.add("drag-over");
});
dropZone.addEventListener("dragleave", () => {
    dropZone.classList.remove("drag-over");
});
dropZone.addEventListener("drop", (e) => {
    e.preventDefault();
    const id = e.dataTransfer.getData("text/plain");
    console.log("Dropped item:", id);
    dropZone.classList.remove("drag-over");
});

MutationObserver — watching DOM changes

MutationObserver watches for DOM changes: added/removed nodes, attribute changes, text content. Useful for third-party widget integration, accessibility monitoring, and auto-updating UI components.

Hindi mein samjhoMutationObserver DOM changes watch karta hai: added/removed nodes, attribute changes. Third-party widgets aur auto-updating UI ke liye useful.
💻 JavaScript — MutationObserver
// ✅ Watch for child changes
const observer = new MutationObserver((mutations) => {
    for (const mutation of mutations) {
        if (mutation.type === "childList") {
            mutation.addedNodes.forEach(node => {
                console.log("Added:", node);
            });
        }
        if (mutation.type === "attributes") {
            console.log(`Attr ${mutation.attributeName} changed`);
        }
    }
});

observer.observe(document.querySelector("#app"), {
    childList: true,     // Watch added/removed children
    attributes: true,    // Watch attribute changes
    subtree: true,       // Watch all descendants
    characterData: true  // Watch text changes
});

// Stop observing
observer.disconnect();

DOM Performance Tips

DOM operations are expensive. Batch changes using DocumentFragment or requestAnimationFrame. Avoid layout thrashing — don't read and write layout properties in alternating sequence. Use event delegation instead of individual handlers.

Hindi mein samjhoDOM operations expensive hain. Batch changes karo DocumentFragment ya requestAnimationFrame se. Layout thrashing avoid karo — read/write alternate mat karo.
💻 JavaScript — DOM Performance
// ❌ Layout thrashing — forces reflow on every iteration
for (const el of elements) {
    el.style.width = el.offsetWidth + 10 + "px"; // Read + Write!
}

// ✅ Read all, then write all
const widths = [...elements].map(el => el.offsetWidth);
elements.forEach((el, i) => {
    el.style.width = widths[i] + 10 + "px";
});

// ✅ Use DocumentFragment for batch inserts
const fragment = document.createDocumentFragment();
data.forEach(item => {
    const el = document.createElement("div");
    el.textContent = item.name;
    fragment.append(el);
});
container.append(fragment); // One DOM update!

// ✅ Use textContent not innerHTML when possible
el.textContent = "Safe text"; // No parsing, no XSS

// ✅ Cache selectors
// ❌ document.querySelector('.btn') inside every click
const btn = document.querySelector(".btn"); // ✅ Cache once
