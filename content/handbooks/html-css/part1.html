1.1

Introduction to the Web & HTML — How the internet works, what is HTML

How the Web Works

When you type a URL in your browser, a request is sent over the internet using the HTTP protocol to a web server. The server responds with files — primarily HTML, CSS, and JavaScript. Your browser then parses the HTML to build the page structure, applies CSS for styling, and executes JavaScript for interactivity.

Hindi mein samjhoJab aap browser me URL type karte ho, browser HTTP protocol se server ko request bhejta hai. Server HTML, CSS, JS files bhejta hai. Browser HTML parse karke page dikhata hai, CSS se styling lagata hai, aur JS se interactivity add hoti hai.

What is HTML?

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It defines the structure and content of a web page using elements (tags). HTML is NOT a programming language — it's a markup language that tells the browser what content to display and how to organize it.

Hindi mein samjhoHTML ek markup language hai jo browser ko batati hai ki page pe kya content hai aur uski structure kya hai. Ye programming language nahi hai — ye content organize karne ka tarika hai.
HTML — Your first HTML
<h1>Hello, World!</h1>
<p>This is my first web page.</p>
A large heading "Hello, World!" followed by a paragraph of text.
Example explained: <h1> creates a top-level heading, <p> creates a paragraph. Together they define content structure.

HTML Elements, Tags & Attributes

An HTML element consists of an opening tag, content, and a closing tag. Some elements are self-closing (like <img>). Attributes provide additional information about elements and are written inside the opening tag.

Hindi mein samjhoHTML element me opening tag, content, aur closing tag hota hai. Kuch elements self-closing hote hain (jaise img). Attributes extra information dete hain jo opening tag me likhe jaate hain.
HTML — Element anatomy
<!-- Regular element: opening tag + content + closing tag -->
<p class="intro">Welcome to HTML!</p>

<!-- Self-closing element (no closing tag needed) -->
<img src="photo.jpg" alt="A beautiful photo">

<!-- Nested elements -->
<div>
  <h2>Title</h2>
  <p>Description here.</p>
</div>
Example explained: class, src, and alt are attributes. Elements can be nested inside other elements to create hierarchy.

How browsers build pages (DOM + render pipeline basics)

Advanced frontend work starts with understanding what the browser does after receiving HTML: it parses HTML into the DOM tree, parses CSS into the CSSOM tree, combines them into a render tree, performs layout calculations, then paints pixels to screen. Poor HTML structure can create fragile CSS and accessibility issues.

Hindi mein samjhoBrowser pehle HTML parse karke DOM banata hai, CSS parse karke CSSOM banata hai, phir render tree bana kar layout aur paint karta hai. Agar HTML structure weak hai to CSS bhi messy hota hai aur accessibility issues badhte hain.

Industry insight: Better semantic structure gives predictable styling, easier QA, better SEO, and fewer regressions in large teams.

HTML Versions & HTML5

HTML has evolved through multiple versions. HTML5 (the current standard) introduced semantic elements, native video/audio support, form validation, and many APIs. Always use HTML5 — declare it with <!DOCTYPE html> at the top of every document.

Hindi mein samjhoHTML5 current standard hai. Ye semantic elements, native video/audio, form validation aur APIs leke aaya. Har HTML file me <!DOCTYPE html> likhna mandatory hai.

1.2

Document Structure & Boilerplate — DOCTYPE, html, head, body, meta

The HTML Boilerplate

Every HTML page starts with a standard structure called the boilerplate. It includes the DOCTYPE declaration, the <html> root element, <head> for metadata, and <body> for visible content. This structure tells the browser how to correctly parse and render your page.

Hindi mein samjhoHar HTML page ek standard structure se shuru hota hai jise boilerplate bolte hain. DOCTYPE browser ko mode batata hai, head me metadata hota hai, aur body me visible content hota hai.
HTML — Complete boilerplate
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Welcome!</h1>
  <p>Content goes here.</p>
</body>
</html>
Example explained: <!DOCTYPE html> activates standards mode. lang="en" declares the page language for accessibility. charset="UTF-8" ensures all characters render correctly.

The <head> section — Metadata

The <head> contains metadata that is not visible on the page but critical for browsers, search engines, and social media. Key elements: <title> (browser tab title + SEO), <meta> (charset, viewport, description), and <link> (external stylesheets, favicon).

Hindi mein samjhoHead section me wo information hoti hai jo page pe dikhai nahi deti — jaise page title (tab me dikhta hai), character encoding, viewport setting, aur CSS file ka link.
HTML — Head metadata
<head>
  <!-- Character encoding (always UTF-8) -->
  <meta charset="UTF-8">

  <!-- Responsive viewport -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Page title (shows in browser tab + Google results) -->
  <title>CodeWithYuvraj — Learn Web Dev</title>

  <!-- SEO description -->
  <meta name="description" content="Learn HTML and CSS from scratch">

  <!-- External stylesheet -->
  <link rel="stylesheet" href="style.css">
</head>
Industry rule: Always include charset, viewport, and title in every page. Missing viewport = broken mobile experience. Missing charset = broken characters.

The <body> section — Visible content

Everything users see on the page goes inside <body>. This includes text, images, links, forms, and interactive elements. The body is where your HTML, styled by CSS and powered by JavaScript, comes to life.

Hindi mein samjhoJo bhi user ko screen pe dikhta hai — text, images, links, buttons — sab body ke andar hota hai. CSS se styling aur JS se behavior add hoti hai.

Production boilerplate checklist (real project baseline)

A professional page should include a consistent base: lang, charset, responsive viewport, meaningful title + description, favicon, CSS link, and often social tags. This avoids common deployment bugs and improves discoverability.

Hindi mein samjhoProfessional HTML page me ek standard baseline hona chahiye: lang, charset, viewport, title, description, favicon, stylesheet link. Isse production me bugs kam hote hain aur SEO better hota hai.

1.3

Text Content Elements — Headings, paragraphs, emphasis, formatting

Headings (h1–h6) — Content hierarchy

HTML provides six levels of headings: <h1> (most important) to <h6> (least important). Headings create a document outline that search engines and screen readers use to understand page structure. Industry rule: use only one h1 per page, and never skip levels (h1 → h3 is wrong).

Hindi mein samjhoHeadings page ka structure define karte hain — h1 sabse important, h6 sabse kam. Ek page me sirf ek h1 hona chahiye. Levels skip mat karo (h1 ke baad seedha h3 mat likho).
HTML — Heading levels
<h1>Main Page Title</h1>
<h2>Section Heading</h2>
<h3>Sub-section</h3>
<h4>Minor heading</h4>
<h5>Rarely used</h5>
<h6>Smallest heading</h6>
SEO Impact: Google uses headings to understand page topic. A clear h1 → h2 → h3 hierarchy improves search rankings and accessibility.

Paragraphs, line breaks & horizontal rules

<p> creates a paragraph — the most common text container. <br> forces a line break within text (use sparingly). <hr> creates a thematic break (horizontal rule) between sections.

Hindi mein samjhoParagraph ke liye <p>, line break ke liye <br>, aur sections ke beech line ke liye <hr> use hota hai. <br> zyada use mat karo — CSS se spacing do.
HTML — Paragraphs & breaks
<p>HTML is the backbone of the web. Every website
you visit uses HTML for structure.</p>

<p>This is a new paragraph.<br>
This line is in the same paragraph but on a new line.</p>

<hr>

<p>A new section starts after the horizontal rule.</p>
Example explained: Browsers collapse multiple spaces and newlines in HTML source into a single space. Use <p> for spacing, not empty lines.

Text emphasis & formatting

<strong> marks text as important (browsers bold it). <em> marks text for emphasis (browsers italicize it). <mark> highlights text. <small> reduces text size. <span> is a generic inline container for styling.

Hindi mein samjho<strong> important text ke liye (bold dikhta hai), <em> emphasis ke liye (italic dikhta hai). <span> generic inline wrapper hai — CSS styling ke liye use hota hai.
HTML — Text formatting
<p>
  This is <strong>very important</strong> text.
  This is <em>emphasized</em> text.
</p>

<p>
  <mark>Highlighted text</mark> stands out.
  <small>Fine print goes here.</small>
</p>

<p>Price: <span class="price">₹1,999</span></p>
Industry tip: Use <strong> and <em> for meaning, not just bold/italic. Screen readers announce them differently. Use CSS for purely visual styling.
1.4

Links & Navigation — Anchor tags, href, paths, targets

The anchor element (<a>)

The <a> (anchor) element creates hyperlinks — the core of web navigation. The href attribute specifies the destination URL. Links can point to external websites, internal pages, sections within a page, email addresses, or phone numbers.

Hindi mein samjho<a> element se hyperlinks bante hain — ye web navigation ka base hai. href attribute destination URL batata hai. Links external sites, internal pages, email, ya phone pe point kar sakte hain.
HTML — Link types
<!-- External link -->
<a href="https://developer.mozilla.org">MDN Web Docs</a>

<!-- Internal page link -->
<a href="about.html">About Us</a>

<!-- Same-page anchor link -->
<a href="#contact">Jump to Contact</a>

<!-- Email and phone links -->
<a href="mailto:codewithyuvraj@gmail.com">Email Me</a>
<a href="tel:+919876543210">Call Me</a>
Example explained: #contact scrolls to the element with id="contact" on the same page. mailto: opens the email client.

target attribute & security

target="_blank" opens links in a new tab. When linking to external sites with _blank, always add rel="noopener noreferrer" for security (prevents the new page from accessing your page's window object).

Hindi mein samjhotarget="_blank" link naye tab me kholte hai. External sites ke liye rel="noopener noreferrer" add karo — ye security ke liye zaroori hai.
HTML — Secure external link
<!-- ✅ Correct: secure external link -->
<a href="https://github.com"
   target="_blank"
   rel="noopener noreferrer">
  GitHub
</a>

<!-- ❌ Wrong: missing rel on external _blank link -->
<a href="https://github.com" target="_blank">GitHub</a>
Security: Without rel="noopener", the linked page can access window.opener and potentially redirect your page. Always add it for external _blank links.

Relative vs absolute paths

Absolute paths include the full URL (https://example.com/page.html). Relative paths are relative to the current file location. Use relative paths for internal links (they work across environments) and absolute paths for external links.

Hindi mein samjhoAbsolute path me full URL likha jaata hai. Relative path current file se relative hota hai. Internal links ke liye relative path use karo — ye deployment me kaam aata hai.
TypeExampleWhen to use
Absolutehttps://example.com/page.htmlExternal sites
Root-relative/images/logo.pngSame domain, from root
Relative../css/style.cssInternal project files
Fragment#section-idSame page scroll
1.5

Images & Media — img, alt, figure, video, audio, lazy loading

The <img> element

<img> embeds images in your page. It's a self-closing element with two required attributes: src (image path) and alt (alternative text for accessibility and SEO). The alt text is read by screen readers and shown when the image fails to load.

Hindi mein samjho<img> se images embed hoti hain. src me image ka path aur alt me description dena mandatory hai — ye accessibility aur SEO dono ke liye zaroori hai.
HTML — Images
<!-- Basic image -->
<img src="photo.jpg" alt="Sunset over mountains">

<!-- Image with width/height (prevents layout shift) -->
<img src="logo.png"
     alt="CodeWithYuvraj logo"
     width="200"
     height="60">

<!-- Lazy loading (loads only when near viewport) -->
<img src="large-photo.jpg"
     alt="High resolution landscape"
     loading="lazy">
Performance tip: Always specify width and height attributes to prevent Cumulative Layout Shift (CLS). Use loading="lazy" for below-fold images.

Responsive images with srcset and sizes

Modern websites should serve different image sizes based on device width and pixel density. srcset lets the browser choose the best file automatically, and sizes tells expected display width. This reduces bandwidth and speeds up mobile loading without losing visual quality.

Hindi mein samjhosrcset aur sizes se browser device ke hisaab se sahi image choose karta hai. Isse mobile pe fast load hota hai aur unnecessary heavy image download nahi hoti.
HTML — responsive images
<img
  src="hero-800.jpg"
  srcset="hero-480.jpg 480w, hero-800.jpg 800w, hero-1200.jpg 1200w"
  sizes="(max-width: 600px) 95vw, (max-width: 1024px) 80vw, 1200px"
  alt="Frontend dashboard preview"
  loading="lazy"
  width="1200"
  height="675">
Example explained: Browser chooses 480w/800w/1200w image automatically based on viewport and DPR, improving performance.

Figure & figcaption

<figure> wraps self-contained content (images, diagrams, code) with an optional <figcaption> for a caption. This is semantically correct — it tells browsers and screen readers that the image and caption are related.

Hindi mein samjho<figure> se image aur uska caption ek group ban jaata hai. Ye semantic HTML hai — browser aur screen reader ko pata chalta hai ki caption us image ka hai.
HTML — Figure with caption
<figure>
  <img src="chart.png" alt="Sales growth chart for Q1 2026">
  <figcaption>Fig 1: Quarterly sales growth in 2026</figcaption>
</figure>

Video & audio elements

HTML5 provides native <video> and <audio> elements — no plugins required. Use controls to show player controls, and provide multiple <source> formats for cross-browser compatibility.

Hindi mein samjhoHTML5 me video aur audio native support hai — koi plugin nahi chahiye. controls attribute se play/pause buttons dikhte hain.
HTML — Video & audio
<!-- Video with controls -->
<video controls width="640">
  <source src="demo.mp4" type="video/mp4">
  <source src="demo.webm" type="video/webm">
  Your browser does not support video.
</video>

<!-- Audio player -->
<audio controls>
  <source src="podcast.mp3" type="audio/mpeg">
</audio>
Example explained: Multiple <source> elements provide format fallbacks. The text inside is shown if the browser doesn't support the element.
1.6

Lists & Basic Grouping — Ordered, unordered, nested, description lists, div

Ordered & unordered lists

<ul> creates an unordered (bulleted) list, <ol> creates an ordered (numbered) list. Each item uses <li>. Lists are essential for navigation menus, feature lists, steps, and any grouped content.

Hindi mein samjho<ul> se bullet points aur <ol> se numbered list banti hai. <li> me har item likha jaata hai. Menus, features, steps — sab lists se bante hain.
HTML — Lists
<!-- Unordered list -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- Ordered list -->
<ol>
  <li>Learn HTML structure</li>
  <li>Add CSS styling</li>
  <li>Make it responsive</li>
</ol>

<!-- Nested list -->
<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Backend</li>
</ul>
Example explained: Lists can be nested inside each other to create hierarchies. Navigation menus are typically built with <ul> inside <nav>.

Description lists & the <div> container

<dl> creates a description list with <dt> (term) and <dd> (definition) — perfect for glossaries and FAQ. <div> is a generic block-level container used to group elements for styling. It has no semantic meaning.

Hindi mein samjho<dl> se glossary ya FAQ type list banti hai. <div> ek generic container hai — CSS styling ke liye grouping karne me use hota hai, iska koi semantic meaning nahi hai.
HTML — Description list & div
<!-- Description list -->
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language — structures web content</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets — styles web content</dd>
</dl>

<!-- div for grouping -->
<div class="card">
  <h3>Project Title</h3>
  <p>Project description here.</p>
</div>
1.7

Comments & Best Practices — HTML comments, readability, naming conventions

HTML comments

Comments in HTML use <!-- ... --> syntax. They are invisible to users but visible in source code. Use them to explain complex sections, mark TODOs, and organize large files. Don't over-comment obvious code.

Hindi mein samjhoHTML comments user ko dikhai nahi dete, lekin source code me hote hain. Complex sections explain karne ke liye aur TODOs mark karne ke liye use karo. Obvious code pe comments mat do.
HTML — Comments
<!-- Navigation Section -->
<nav>
  <!-- Main navigation links -->
  <a href="/">Home</a>
  <a href="/about">About</a>
</nav>

<!-- TODO: Add footer with social links -->
