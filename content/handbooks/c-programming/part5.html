5.1

Structure Basics — Definition, initialization, accessing members, nested

What is a struct?

A struct groups related variables of different types into a single unit. Think of it as creating a custom data type. Unlike arrays (same type), structs can hold mixed types — like a student record with name, age, and GPA together.

Hindi mein samjhoStruct related variables ko ek unit me group karta hai — different types ke. Ye custom data type banane jaisa hai. Array me same type hota hai, struct me mixed types ho sakte hain — jaise student ka naam, age, aur GPA ek saath.
💻 C — Struct basics
/* Define a struct */
struct Student {
    char name[50];
    int age;
    double gpa;
    int roll_no;
};

/* Declare & initialize */
struct Student s1 = {"Yuvraj", 21, 3.85, 101};

/* Designated initializers (C99+) — preferred! */
struct Student s2 = {
    .name = "Rahul",
    .age = 22,
    .gpa = 3.90,
    .roll_no = 102
};

/* Access members with dot operator */
printf("Name: %s\n", s1.name);
printf("GPA:  %.2f\n", s1.gpa);

/* Modify members */
s1.age = 22;
s1.gpa = 3.95;

Nested structs

💻 C — Nested structs
struct Date {
    int day, month, year;
};

struct Employee {
    char name[50];
    double salary;
    struct Date join_date;  /* Nested struct */
};

struct Employee emp = {
    .name = "Priya",
    .salary = 75000.0,
    .join_date = {.day = 15, .month = 3, .year = 2024}
};

printf("Joined: %d/%d/%d\n",
    emp.join_date.day, emp.join_date.month, emp.join_date.year);
5.2

Advanced Structs — Pointers to structs, arrays of structs, self-referential

Pointers to structs (arrow operator)

When you have a pointer to a struct, use the arrow operator -> instead of dot. ptr->member is equivalent to (*ptr).member. This is used everywhere — function parameters, linked lists, dynamic allocation.

Hindi mein samjhoStruct ke pointer pe arrow operator -> use karo dot ki jagah. ptr->member same hai (*ptr).member ke. Ye function parameters, linked lists, dynamic allocation me har jagah use hota hai.
💻 C — Struct pointers
struct Student s = {"Yuvraj", 21, 3.85, 101};
struct Student *ptr = &s;

/* Arrow operator — clean syntax */
printf("%s\n", ptr->name);   /* Yuvraj */
printf("%d\n", ptr->age);    /* 21 */

/* Equivalent but ugly */
printf("%s\n", (*ptr).name); /* Same thing */

/* Dynamic allocation */
struct Student *p = malloc(sizeof(struct Student));
strcpy(p->name, "Dynamic");
p->age = 20;
p->gpa = 3.70;
free(p);

Array of structs & self-referential structs

💻 C — Array of structs & linked list node
/* Array of structs */
struct Student class[30];
class[0] = (struct Student){"Alice", 20, 3.9, 1};
class[1] = (struct Student){"Bob", 21, 3.5, 2};

/* Self-referential struct (for linked lists!) */
struct Node {
    int data;
    struct Node *next;  /* Points to another Node */
};

/* Create a 3-node linked list */
struct Node n3 = {30, NULL};
struct Node n2 = {20, &n3};
struct Node n1 = {10, &n2};

/* Traverse: n1 → n2 → n3 → NULL */
struct Node *curr = &n1;
while (curr != NULL) {
    printf("%d → ", curr->data);
    curr = curr->next;
}
printf("NULL\n");  /* 10 → 20 → 30 → NULL */
Foundation for DSA: Self-referential structs are the building block for ALL dynamic data structures — linked lists, trees, graphs, stacks, and queues. Master this pattern now; Part 7 builds on it heavily.
5.3

Memory Layout & Padding — Alignment, sizeof struct, packed structs

Why structs have padding

CPUs access memory most efficiently at aligned addresses (e.g., a 4-byte int at an address divisible by 4). The compiler inserts padding bytes between struct members to ensure alignment. This means sizeof(struct) is often larger than the sum of member sizes.

Hindi mein samjhoCPUs aligned addresses pe memory efficiently access karte hain (e.g., 4-byte int address divisible by 4 pe). Compiler struct members ke beech padding bytes dalta hai alignment ke liye. Isliye sizeof(struct) members ke sum se bada hota hai.
💻 C — Padding example
#include <stddef.h>  /* for offsetof */

struct Bad {
    char a;      /* 1 byte + 3 padding */
    int b;       /* 4 bytes */
    char c;      /* 1 byte + 3 padding */
};  /* Total: 12 bytes (not 6!) */

struct Good {
    int b;       /* 4 bytes */
    char a;      /* 1 byte */
    char c;      /* 1 byte + 2 padding */
};  /* Total: 8 bytes — saved 33%! */

printf("Bad:  %zu\n", sizeof(struct Bad));   /* 12 */
printf("Good: %zu\n", sizeof(struct Good));  /* 8 */

/* Use offsetof to see member positions */
printf("a offset: %zu\n", offsetof(struct Bad, a)); /* 0 */
printf("b offset: %zu\n", offsetof(struct Bad, b)); /* 4 */
printf("c offset: %zu\n", offsetof(struct Bad, c)); /* 8 */

Optimization rule: Order struct members from largest to smallest to minimize padding. This can save significant memory in arrays of millions of structs (databases, games, scientific computing).
5.4

Unions & Tagged Unions — Memory-efficient variants, type-punning

What is a union?

A union looks like a struct, but all members share the same memory. Only one member can be used at a time. The size of a union equals the size of its largest member. Unions save memory when a variable can be one of several types.

Hindi mein samjhoUnion struct jaisa dikhta hai, par sabhi members same memory share karte hain. Ek time pe sirf ek member use ho sakta hai. Union ka size largest member ke barabar hota hai. Jab variable kisi ek type ka ho — tab memory bachane ke liye union use hota hai.
💻 C — Union basics
union Data {
    int i;        /* 4 bytes */
    float f;      /* 4 bytes */
    char str[20]; /* 20 bytes */
};
/* sizeof(union Data) = 20 (largest member) */

union Data d;
d.i = 42;
printf("%d\n", d.i);  /* 42 ✅ */

d.f = 3.14;
/* d.i is now GARBAGE — they share memory! */
printf("%f\n", d.f);  /* 3.14 ✅ */
printf("%d\n", d.i);  /* Garbage ❌ */

Tagged union (discriminated union)

A tagged union combines a union with an enum "tag" that tracks which member is currently active. This is the safe, industry-standard pattern — used in parsers, interpreters, and protocol handlers.

Hindi mein samjhoTagged union me union ke saath ek enum "tag" hota hai jo batata hai kaunsa member abhi active hai. Ye safe, industry-standard pattern hai — parsers, interpreters, aur protocol handlers me use hota hai.
💻 C — Tagged union
enum ValueType { TYPE_INT, TYPE_FLOAT, TYPE_STRING };

struct Value {
    enum ValueType type;  /* Tag — tracks active member */
    union {
        int i;
        float f;
        char str[32];
    } data;
};

void print_value(struct Value v) {
    switch (v.type) {
        case TYPE_INT:    printf("%d\n", v.data.i); break;
        case TYPE_FLOAT:  printf("%f\n", v.data.f); break;
        case TYPE_STRING: printf("%s\n", v.data.str); break;
    }
}

struct Value v = {.type = TYPE_INT, .data.i = 42};
print_value(v);  /* 42 */

5.5

Enumerations — Named constants, readability, state machines

enum basics

An enum creates a set of named integer constants. It makes code more readable and self-documenting. By default, values start at 0 and increment by 1, but you can assign custom values.

Hindi mein samjhoenum named integer constants ka set banata hai. Code readable aur self-documenting banta hai. Default me values 0 se start hoti hain aur 1 se increment, par custom values bhi de sakte ho.
💻 C — Enumerations
/* Basic enum */
enum Color { RED, GREEN, BLUE };  /* 0, 1, 2 */

/* Custom values */
enum HttpStatus {
    HTTP_OK = 200,
    HTTP_NOT_FOUND = 404,
    HTTP_SERVER_ERROR = 500
};

/* State machine pattern */
enum State { STATE_IDLE, STATE_RUNNING, STATE_ERROR, STATE_DONE };

enum State current = STATE_IDLE;

switch (current) {
    case STATE_IDLE:    start_process();  current = STATE_RUNNING; break;
    case STATE_RUNNING: check_progress(); break;
    case STATE_ERROR:   handle_error();   current = STATE_IDLE; break;
    case STATE_DONE:    cleanup();        break;
}
Best practice: Use enums instead of #define for related constants. Enums are type-checked by the compiler, show up in debuggers, and group related values together.
5.6

typedef & Type Aliases — Portability, readability, opaque types

typedef creates aliases

typedef creates a new name for an existing type. It makes code more readable, portable, and enables opaque types (hiding implementation details). Every major C project uses typedef extensively.

Hindi mein samjhotypedef existing type ko naya naam deta hai. Code readable, portable banta hai, aur opaque types (implementation details chhupana) possible hote hain. Har major C project typedef use karta hai.
💻 C — typedef
/* Simple type alias */
typedef unsigned int uint;
typedef unsigned char byte;

uint count = 100;
byte pixel = 255;

/* Struct typedef — avoids writing 'struct' every time */
typedef struct {
    double x, y;
} Point;

Point p1 = {3.0, 4.0};  /* No 'struct' keyword needed */

/* Function pointer typedef */
typedef int (*Comparator)(const void*, const void*);
Comparator cmp = compare_asc;  /* Much cleaner! */

/* Opaque type (hide implementation) */
/* In header: */
typedef struct Database Database;  /* Forward declaration */
Database* db_open(const char *path);
void db_close(Database *db);
/* User can't access internals — clean API! */

5.7

Bit Fields — Hardware register mapping, compact data storage

What are bit fields?

Bit fields let you specify the exact number of bits a struct member uses. They're essential for: hardware register mapping (embedded systems), network protocol headers, and compact data storage when memory is limited.

Hindi mein samjhoBit fields se struct member me exact bits specify kar sakte ho. Hardware register mapping (embedded systems), network protocol headers, aur compact data storage ke liye zaroori hain jab memory limited ho.
💻 C — Bit fields
/* Compact flags — uses only 1 byte instead of 16! */
struct Permissions {
    unsigned int read    : 1;  /* 1 bit: 0 or 1 */
    unsigned int write   : 1;
    unsigned int execute : 1;
    unsigned int admin   : 1;
};

struct Permissions p = {.read = 1, .write = 1, .execute = 0, .admin = 0};

if (p.read) printf("Can read\n");
if (p.admin) printf("Is admin\n");

/* Hardware register mapping (embedded C) */
struct StatusReg {
    unsigned int ready    : 1;
    unsigned int error    : 1;
    unsigned int mode     : 3;  /* 3 bits: 0-7 */
    unsigned int speed    : 2;  /* 2 bits: 0-3 */
    unsigned int reserved : 1;
};
Portability warning: Bit field layout (order, padding) is implementation-defined — different compilers may order bits differently. For cross-platform code, use explicit bitwise operations instead. Bit fields are best for single-platform embedded work.

Packed structs — removing padding

Sometimes you need structs without padding — for network protocols, file formats, or binary data. GCC/Clang provide __attribute__((packed)) and MSVC uses #pragma pack. Warning: packed structs can cause slower memory access on some architectures.

Hindi mein samjhoKabhi kabhi structs bina padding ke chahiye — network protocols, file formats, ya binary data ke liye. GCC/Clang me __attribute__((packed)) aur MSVC me #pragma pack use hota hai. Warning: packed structs se kuch architectures pe slow memory access hota hai.
💻 C — Packed structs
/* GCC/Clang — packed attribute */
struct __attribute__((packed)) NetworkPacket {
    uint8_t  version;     /* 1 byte */
    uint16_t length;      /* 2 bytes */
    uint32_t source_ip;   /* 4 bytes */
    uint32_t dest_ip;     /* 4 bytes */
    uint16_t checksum;    /* 2 bytes */
};  /* sizeof = 13 (no padding!) */

/* Without packed: sizeof = 16 (3 bytes wasted) */

/* MSVC equivalent */
#pragma pack(push, 1)
struct PackedData {
    char a;
    int b;
    char c;
};  /* sizeof = 6 instead of 12 */
#pragma pack(pop)

Real-world struct patterns used in industry

Here are patterns you'll find in production C codebases — from Linux kernel modules to game engines to embedded firmware. Understanding these patterns makes you interview-ready.

Hindi mein samjhoYe patterns production C codebases me milte hain — Linux kernel modules se game engines se embedded firmware tak. Ye patterns samajhna interview-ready banata hai.
💻 C — Industry patterns
/* Pattern 1: Constructor/Destructor pattern */
typedef struct {
    char *data;
    size_t length;
    size_t capacity;
} String;

String string_new(const char *init) {
    size_t len = strlen(init);
    String s = {
        .data = malloc(len + 1),
        .length = len,
        .capacity = len + 1
    };
    strcpy(s.data, init);
    return s;
}

void string_free(String *s) {
    free(s->data);
    s->data = NULL;
    s->length = 0;
    s->capacity = 0;
}

/* Pattern 2: Flexible array member (C99+) */
struct Packet {
    uint16_t type;
    uint16_t length;
    uint8_t  data[];  /* Flexible array — must be last member */
};

/* Allocate packet with N bytes of data */
struct Packet *pkt = malloc(sizeof(struct Packet) + 1024);
pkt->type = 1;
pkt->length = 1024;
memcpy(pkt->data, payload, 1024);

/* Pattern 3: Vtable (virtual function table) — OOP in C */
typedef struct Shape Shape;
typedef struct {
    double (*area)(Shape *self);
    void   (*draw)(Shape *self);
    void   (*destroy)(Shape *self);
} ShapeVtable;

struct Shape {
    const ShapeVtable *vtable;  /* Pointer to method table */
};

/* Usage: shape->vtable->area(shape); */
Interview gold: "How do you implement polymorphism in C?" → Answer: vtable pattern with function pointers. This is exactly how the Linux kernel handles device drivers, file systems, and network protocols.
