1.1

History & Why C Matters — C's role in OS, embedded systems, and modern computing

The birth of C

C was created by Dennis Ritchie at Bell Labs in 1972 to rewrite the Unix operating system. Before C, OS code was written in assembly — tied to specific hardware. C provided a portable, high-level language that could still access hardware directly. This made Unix — and later Linux, Windows, and macOS — possible.

Hindi mein samjhoC ko Dennis Ritchie ne 1972 me Bell Labs me banaya tha Unix OS likhne ke liye. Pehle OS assembly me likha jaata tha jo specific hardware pe hi chalta tha. C ne portable, high-level language di jo hardware ko directly access bhi kar sakti thi.

Why C still matters in 2026

C is the #2 language on the TIOBE index. It powers: Linux kernel (28M+ lines of C), Windows kernel, Python interpreter (CPython is written in C), Git, PostgreSQL, and virtually every embedded device (cars, medical devices, satellites). Learning C means understanding how computers actually work.

Hindi mein samjhoC aaj bhi TIOBE index pe #2 hai. Linux kernel, Windows kernel, Python interpreter, Git — sab C me likhe hain. Har embedded device (cars, medical, satellites) C use karta hai. C sikhna = computer samajhna.

Setting Up the Environment — GCC, VS Code, and your first compile

Installing GCC (the C compiler)

GCC (GNU Compiler Collection) is the most widely used C compiler. On Windows, install it via MinGW-w64 or MSYS2. On macOS, install Xcode Command Line Tools. On Linux, GCC is usually pre-installed. After installation, verify with gcc --version.

Hindi mein samjhoGCC sabse popular C compiler hai. Windows pe MinGW-w64 ya MSYS2 se install karo. macOS pe Xcode Command Line Tools install karo. Linux pe pehle se installed hota hai. gcc --version se verify karo.
💻 Terminal — Installation & verification
# Windows (MSYS2 — recommended)
pacman -S mingw-w64-ucrt-x86_64-gcc

# macOS
xcode-select --install

# Ubuntu/Debian Linux
sudo apt update && sudo apt install build-essential

# Verify installation (all platforms)
gcc --version
# gcc (GCC) 13.2.0 ...

VS Code setup for C

Install VS Code, then add the C/C++ extension by Microsoft (ms-vscode.cpptools). This gives you IntelliSense, debugging, and error highlighting. Configure your tasks.json to compile with gcc on save.

Hindi mein samjhoVS Code install karo, phir Microsoft ka C/C++ extension add karo. IntelliSense, debugging, aur error highlighting mil jayegi.

Your first compile & run

💻 C — hello.c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
💻 Terminal — Compile & run
# Compile
gcc hello.c -o hello

# Run
./hello
# Output: Hello, World!
Pro tip: Always compile with warnings enabled: gcc -Wall -Wextra -Werror hello.c -o hello. This catches bugs before they reach production.
1.3

Structure of a C Program — #include, main(), return, comments

Anatomy of a C program

Every C program has a specific structure: preprocessor directives at the top, then function declarations, then the main() function which is the entry point. The return 0; tells the OS the program exited successfully.

Hindi mein samjhoHar C program ka ek structure hota hai: sabse upar preprocessor directives, phir function declarations, phir main() function jo entry point hai. return 0; OS ko bolta hai ki program successfully complete hua.
💻 C — Complete program structure
/* ===== 1. Preprocessor Directives ===== */
#include <stdio.h>    /* Standard I/O library */
#include <stdlib.h>   /* Standard utility library */
#define MAX_SIZE 100 /* Constant macro */

/* ===== 2. Function Declarations ===== */
void greet(void);     /* Forward declaration */

/* ===== 3. Main Function (Entry Point) ===== */
int main(void) {
    greet();
    return 0;          /* 0 = success, non-zero = error */
}

/* ===== 4. Function Definitions ===== */
void greet(void) {
    printf("Welcome to C!\n");
}

Comments in C

Comments are ignored by the compiler. Use /* */ for multi-line and // for single-line (C99+). Good comments explain why, not what. The code should be clear enough to show what it does.

Hindi mein samjhoComments compiler ignore karta hai. /* */ multi-line ke liye aur // single-line ke liye (C99+). Achhe comments "why" explain karte hain, "what" nahi — code khud clear hona chahiye.
💻 C — Comments
/* Multi-line comment
   Used for documentation blocks
   and file headers */

// Single-line comment (C99+)

// ❌ BAD: tells you WHAT (obvious from code)
int x = 5; // set x to 5

// ✅ GOOD: tells you WHY
int retries = 5; // Max retries before timeout (per RFC 2616)

The main() function — entry point

main() is where execution begins. It must return int. Return 0 for success, non-zero for error. There are two valid signatures:

Hindi mein samjhomain() se execution shuru hota hai. Ye int return karta hai. 0 success hai, non-zero error hai.
SignatureWhen to useExample
int main(void)No command-line argsSimple programs
int main(int argc, char *argv[])With command-line argsCLI tools
Never use: void main() — this is NOT valid C. It may compile on some systems but is undefined behavior per the C standard.

1.5

Data Types & Variables — int, char, float, double, void, sizeof

Primitive data types in C

C is a statically typed language — every variable must have a type declared before use. The type determines how much memory is allocated and how the bits are interpreted. Choosing the right type affects both memory efficiency and correctness.

Hindi mein samjhoC statically typed hai — har variable ka type pehle se declare karna padta hai. Type decide karta hai kitni memory lagegi aur bits ka matlab kya hoga.
TypeSize (typical)RangeUse case
char1 byte-128 to 127Characters, small numbers
short2 bytes-32,768 to 32,767Small integers
int4 bytes-2.1B to 2.1BGeneral integers ✅
long4/8 bytesPlatform-dependentLarge integers
long long8 bytes±9.2 × 10¹⁸Very large integers
float4 bytes±3.4 × 10³⁸ (6 digits)Decimal (low precision)
double8 bytes±1.7 × 10³⁰⁸ (15 digits)Decimal ✅ (standard)
void0 bytesN/ANo value / generic pointer

Variable declaration & initialization

💻 C — Variables
/* Declaration (allocates memory, value is garbage) */
int age;
char grade;

/* Initialization (declaration + value) */
int age = 21;
char grade = 'A';
float gpa = 3.85f;      /* 'f' suffix for float */
double pi = 3.14159265358979;

/* Multiple declarations */
int x = 1, y = 2, z = 3;

/* Type modifiers */
unsigned int count = 0;     /* Only positive: 0 to 4.2B */
signed int temp = -15;      /* Positive & negative (default) */
long long int big = 9000000000LL;
Common bug: Uninitialized variables contain garbage values (whatever was in that memory). Always initialize variables when declaring them.

sizeof operator

sizeof returns the size in bytes of a type or variable. It's evaluated at compile time, not runtime — so it has zero performance cost.

Hindi mein samjhosizeof type ya variable ka size bytes me batata hai. Ye compile time pe evaluate hota hai — runtime pe koi cost nahi.
💻 C — sizeof
#include <stdio.h>

int main(void) {
    printf("char:      %zu bytes\n", sizeof(char));
    printf("int:       %zu bytes\n", sizeof(int));
    printf("float:     %zu bytes\n", sizeof(float));
    printf("double:    %zu bytes\n", sizeof(double));
    printf("long long: %zu bytes\n", sizeof(long long));
    printf("pointer:   %zu bytes\n", sizeof(int *));
    return 0;
}
1.6

Constants & Literals — const, #define, escape sequences

Constants — values that never change

Constants prevent accidental modification. Use const for type-safe constants and #define for compile-time macros. const is preferred in modern C because the compiler can type-check it.

Hindi mein samjhoConstants woh values hain jo kabhi change nahi hoti. const type-safe hai aur #define compile-time macro hai. Modern C me const preferred hai kyunki compiler type-check kar sakta hai.
💻 C — Constants
/* Method 1: const (preferred — type-safe) */
const int MAX_STUDENTS = 100;
const double PI = 3.14159265358979;
const char NEWLINE = '\n';

/* Method 2: #define (preprocessor macro) */
#define MAX_BUFFER 1024
#define VERSION "1.0.0"
#define SQUARE(x) ((x) * (x))

/* Method 3: enum (for related integer constants) */
enum { RED = 0, GREEN = 1, BLUE = 2 };

const✅ YesBlock scopeLocal/file constants
#define❌ No (text replace)GlobalMacros, config values
enum✅ Yes (int)Block scopeRelated integer sets

Escape sequences

Escape sequences represent special characters inside strings and character literals. They start with a backslash \.

Hindi mein samjhoEscape sequences special characters ko represent karte hain strings ke andar. Ye backslash \ se shuru hote hain.
EscapeMeaningExample output
\nNewlineLine break

\\Backslash\

Input & Output — printf format specifiers, scanf, getchar, fgets

printf — formatted output

printf writes formatted text to stdout (the terminal). It uses format specifiers starting with % to insert variable values. Understanding format specifiers is essential — wrong ones cause undefined behavior.

scanf — formatted input

scanf reads formatted input from stdin. It requires the address-of operator (&) for each variable. Be careful — scanf with %s is unsafe (no bounds checking).

Hindi mein samjhoscanf keyboard se input leta hai. Har variable ke saath & (address-of) lagana padta hai. %s ke saath scanf unsafe hai — bounds check nahi karta.
💻 C — scanf examples
#include <stdio.h>

int main(void) {
    int age;
    char name[50];
    double gpa;

    /* Reading an integer */
    printf("Enter age: ");
    scanf("%d", &age);    /* & is REQUIRED! */

    /* Reading a float */
    printf("Enter GPA: ");
    scanf("%lf", &gpa);   /* %lf for double! */

    /* ❌ UNSAFE: scanf with %s (no limit) */
    scanf("%s", name);     /* Buffer overflow risk! */

    /* ✅ SAFE: fgets (preferred for strings) */
    printf("Enter name: ");
    fgets(name, 50, stdin); /* Max 49 chars + \0 */

    printf("Hello %s, age %d, GPA %.2f\n", name, age, gpa);
    return 0;
}
Security rule: NEVER use scanf("%s", ...) or gets() for string input. They have no bounds checking and are the #1 cause of buffer overflow vulnerabilities. Use fgets() instead.

Character I/O — getchar & putchar

For single characters, getchar() reads one character and putchar() writes one. These are faster than printf/scanf for character-level processing.

Hindi mein samjhoSingle character ke liye getchar() read karta hai aur putchar() write karta hai. Ye printf/scanf se fast hain character-level processing ke liye.
💻 C — Character I/O
#include <stdio.h>

int main(void) {
    int ch;  /* int, not char! (to detect EOF) */

    printf("Type a character: ");
    ch = getchar();

    printf("You typed: ");
    putchar(ch);
    putchar('\n');

    return 0;
}
Why int, not char? getchar() returns int because it needs to return EOF (-1) when input ends. If you use char, you can't distinguish EOF from valid data on some systems.
