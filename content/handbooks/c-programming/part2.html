Arithmetic & Assignment Operators — +, -, *, /, %, compound assignment

Arithmetic operators

Arithmetic operators perform mathematical calculations. The key gotcha in C: integer division truncates — 7 / 2 gives 3, not 3.5. The modulo operator % gives the remainder and only works with integers.

Hindi mein samjhoArithmetic operators math calculations karte hain. C ka important gotcha: integer division truncate hota hai — 7 / 2 = 3, 3.5 nahi. Modulo % remainder deta hai aur sirf integers pe kaam karta hai.

-Subtraction5 - 32
*Multiplication5 * 315
/Division7 / 23⚠️ Truncates for ints!
/Float division7.0 / 23.5One operand must be float
%Modulo7 % 21Integers only
++Incrementx++x + 1Post vs pre: x++ vs ++x
--Decrementx--x - 1Post vs pre: x-- vs --x

Pre-increment vs post-increment

💻 C — ++ and --
int a = 5;

/* Post-increment: use THEN increment */
int b = a++;   /* b = 5, a = 6 */

/* Pre-increment: increment THEN use */
int c = ++a;   /* a = 7, c = 7 */

printf("a=%d b=%d c=%d\n", a, b, c);
/* Output: a=7 b=5 c=7 */
Interview trap: Never use ++ on the same variable multiple times in one expression like x = x++ + ++x. This is undefined behavior — the result varies across compilers.

Relational & Logical Operators — Comparison, boolean logic, short-circuit

Relational operators (comparison)

Relational operators compare two values and return 1 (true) or 0 (false). C has no built-in bool type in C89 — it uses integers. C99 added <stdbool.h> with true/false.

Hindi mein samjhoRelational operators do values compare karte hain aur 1 (true) ya 0 (false) return karte hain. C89 me built-in bool nahi tha — integers use hote the. C99 me stdbool.h aaya.
OperatorMeaningExampleResult
==Equal to5 == 51 (true)
!=Not equal5 != 31 (true)
<Less than3 < 51 (true)
>Greater than3 > 50 (false)
<=Less or equal5 <= 51 (true)
>=Greater or equal3 >= 50 (false)
Classic bug: if (x = 5) is ASSIGNMENT (always true), not comparison! Use if (x == 5). Pro tip: write if (5 == x) — the compiler catches 5 = x as an error.

Logical operators & short-circuit evaluation

Logical operators combine boolean conditions. Short-circuit evaluation means C stops evaluating as soon as the result is determined: in A && B, if A is false, B is never evaluated. This is used for null-pointer safety.

Hindi mein samjhoLogical operators boolean conditions combine karte hain. Short-circuit evaluation me C jaldi result decide kar leta hai: A && B me agar A false hai toh B evaluate hi nahi hota. Ye null-pointer safety ke liye use hota hai.
OperatorMeaningShort-circuit?Example
&&Logical AND✅ Stops if left is falsex > 0 && x < 100
||Logical OR✅ Stops if left is truex == 0 || x == 1
!Logical NOTN/A!done
💻 C — Short-circuit for safety
/* Short-circuit prevents null pointer crash */
int *ptr = get_data();

/* If ptr is NULL, *ptr is NEVER accessed ✅ */
if (ptr != NULL && *ptr > 0) {
    printf("Value: %d\n", *ptr);
}

/* Without short-circuit — this would CRASH if ptr is NULL ❌ */

Bitwise Operators — &, |, ^, ~, <<, >> — hardware-level control

Why bitwise matters

Bitwise operators work on individual bits of integers. They're essential for: embedded systems (controlling hardware registers), network protocols (parsing packet headers), graphics (color manipulation), and performance optimization (faster than multiplication/division).

Hindi mein samjhoBitwise operators individual bits pe kaam karte hain. Embedded systems (hardware registers), network protocols (packet headers), graphics (color manipulation), aur performance optimization ke liye zaroori hain.
OperatorNameExample (binary)Result
&AND1100 & 10101000
|OR1100 | 10101110
^XOR1100 ^ 10100110
~NOT (complement)~11000011
<<Left shift0001 << 20100 (×4)
>>Right shift1000 >> 20010 (÷4)

Bit manipulation patterns (interview essentials)

💻 C — Bit manipulation
unsigned int reg = 0b10110100;

/* SET a bit (turn ON bit 1) */
reg |= (1 << 1);    /* reg = 0b10110110 */

/* CLEAR a bit (turn OFF bit 2) */
reg &= ~(1 << 2);   /* reg = 0b10110010 */

/* TOGGLE a bit (flip bit 4) */
reg ^= (1 << 4);    /* reg = 0b10100010 */

/* CHECK a bit (is bit 5 set?) */
if (reg & (1 << 5)) {
    printf("Bit 5 is ON\n");
}

/* Multiply by 2^n using left shift */
int x = 5;
int y = x << 3;     /* y = 5 * 8 = 40 */

/* Divide by 2^n using right shift */
int z = 40 >> 2;     /* z = 40 / 4 = 10 */

/* Swap two variables without temp (XOR trick) */
int a = 10, b = 20;
a ^= b; b ^= a; a ^= b;
/* Now a = 20, b = 10 */

/* Check if number is even/odd */
if (n & 1) printf("Odd\n");
else       printf("Even\n");
Embedded C essential: Hardware registers are controlled entirely through bitwise operations. REG |= (1 << BIT) to set, REG &= ~(1 << BIT) to clear. Memorize these patterns.

Operator Precedence & Type Casting — evaluation order, implicit vs explicit

Operator precedence table (memorize the top 5)

When multiple operators appear in one expression, precedence determines which is evaluated first. Associativity determines order when operators have equal precedence. When in doubt, use parentheses.

Hindi mein samjhoEk expression me multiple operators ho toh precedence decide karta hai kaunsa pehle evaluate hoga. Associativity equal precedence me order decide karti hai. Doubt ho toh parentheses lagao.
PriorityOperatorDescriptionAssociativity
1 (highest)() [] -> .Grouping, accessLeft → Right
2! ~ ++ -- + - * & sizeofUnary operatorsRight → Left
3* / %MultiplicationLeft → Right
4+ -AdditionLeft → Right
5<< >>Bit shiftLeft → Right
6< <= > >=RelationalLeft → Right
7== !=EqualityLeft → Right
8&Bitwise ANDLeft → Right
9^Bitwise XORLeft → Right
10|Bitwise ORLeft → Right
11&&Logical ANDLeft → Right

Rule of thumb: If you have to think about precedence, add parentheses. (a & b) == 0 is clearer than a & b == 0 (which actually means a & (b == 0) — a common bug!).

Type casting — implicit vs explicit

Implicit casting (type promotion) happens automatically when mixing types. Explicit casting uses the cast operator (type). Always cast explicitly to make intent clear and prevent bugs.

Hindi mein samjhoImplicit casting (type promotion) automatically hota hai jab different types mix hote hain. Explicit casting me (type) operator use karte hain. Hamesha explicitly cast karo — intent clear rehta hai.
💻 C — Type casting
/* Implicit promotion (automatic) */
int a = 5;
double b = a;       /* int → double (safe, no data loss) */

/* Implicit truncation (DANGEROUS!) */
double pi = 3.14;
int x = pi;          /* ⚠️ x = 3 (decimal part LOST) */

/* Explicit cast (preferred — shows intent) */
int total = 7, count = 2;
double avg = (double)total / count;  /* 3.5 ✅ */
double wrong = total / count;        /* 3.0 ❌ (int division first!) */

/* Promotion hierarchy: char → int → long → float → double */
2.5

Conditional Statements — if, else-if, switch-case, ternary

if, else-if, else

Conditionals let your program make decisions. if checks a condition; if true, the block executes. else if adds alternative checks. else catches everything remaining. In C, any non-zero value is true and 0 is false.

Hindi mein samjhoConditionals se program decisions le sakta hai. if condition check karta hai; true ho toh block execute hota hai. C me koi bhi non-zero value true hai aur 0 false hai.
💻 C — if / else-if / else
int score = 85;

if (score >= 90) {
    printf("Grade: A\n");
} else if (score >= 80) {
    printf("Grade: B\n");
} else if (score >= 70) {
    printf("Grade: C\n");
} else {
    printf("Grade: F\n");
}

/* C truth values: 0 = false, anything else = true */
int x = 42;
if (x) printf("This prints! (42 is truthy)\n");

int y = 0;
if (y) printf("This does NOT print (0 is falsy)\n");

switch-case

switch compares one value against multiple constants. It's cleaner than long else-if chains for discrete values. Always include break to prevent fall-through (executing the next case too) and a default case.

Hindi mein samjhoswitch ek value ko multiple constants se compare karta hai. Discrete values ke liye long else-if se clean hai. break hamesha lagao warna fall-through hota hai.
💻 C — switch-case
char op = '+';
int a = 10, b = 3;

switch (op) {
    case '+': printf("%d\n", a + b); break;
    case '-': printf("%d\n", a - b); break;
    case '*': printf("%d\n", a * b); break;
    case '/':
        if (b != 0) printf("%d\n", a / b);
        else printf("Division by zero!\n");
        break;
    default:
        printf("Unknown operator\n");
}

Ternary operator

The ternary operator condition ? value_if_true : value_if_false is a compact if-else for simple assignments. Don't nest them — it becomes unreadable.

Hindi mein samjhoTernary operator condition ? true_value : false_value simple if-else ka compact version hai. Nest mat karo — unreadable ho jaata hai.
💻 C — Ternary
int age = 18;

/* ✅ Good: simple assignment */
char *status = (age >= 18) ? "Adult" : "Minor";

/* ✅ Good: inline in printf */
printf("Max: %d\n", (a > b) ? a : b);

/* ❌ Bad: nested ternary (unreadable) */
int result = (x > 0) ? ((x > 100) ? 100 : x) : 0;
2.6

Loops — for, while, do-while, break, continue, nested loops

Three types of loops

Loops repeat code blocks. for is best when you know the count. while when you have a condition. do-while when the body must execute at least once. Choose the right loop for readable, bug-free code.

Hindi mein samjhoLoops code blocks repeat karte hain. for jab count pata ho, while jab condition ho, do-while jab body kam se kam ek baar execute hona chahiye.
💻 C — All three loops
/* FOR loop — known iteration count */
for (int i = 0; i < 5; i++) {
    printf("%d ", i);  /* 0 1 2 3 4 */
}

/* WHILE loop — condition-based */
int n = 1;
while (n <= 100) {
    n *= 2;  /* Double until > 100 */
}
printf("n = %d\n", n);  /* 128 */

/* DO-WHILE — executes at least once */
int input;
do {
    printf("Enter 1-10: ");
    scanf("%d", &input);
} while (input < 1 || input > 10);
LoopCheckMin executionsBest for
forBefore each iteration0Known count, arrays
whileBefore each iteration0Unknown count, streams
do-whileAfter each iteration1Input validation, menus

break & continue

break exits the loop entirely. continue skips to the next iteration. Both work inside for, while, and do-while.

Hindi mein samjhobreak loop se bahar nikal jaata hai. continue current iteration skip karke next pe jaata hai.
💻 C — break & continue
/* break — exit loop early */
for (int i = 0; i < 100; i++) {
    if (arr[i] == target) {
        printf("Found at %d\n", i);
        break;  /* Stop searching */
    }
}

/* continue — skip odd numbers */
for (int i = 0; i < 10; i++) {
    if (i % 2 != 0) continue;
    printf("%d ", i);  /* 0 2 4 6 8 */
}

/* Nested loop with break */
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        if (j > i) break;
        printf("* ");
    }
    printf("\n");
}
/* Output:
 * 
 * * 
 * * * 
 * * * * 
 * * * * *  */
Infinite loop: while(1) or for(;;) runs forever. Always ensure there's a break condition inside. Used intentionally in embedded systems for main event loops.
2.7

goto, Scope & Storage Classes — auto, static, extern, register

goto — when it's acceptable

goto jumps to a labeled statement. It's generally avoided because it creates spaghetti code. The one acceptable use is for error cleanup in functions with multiple resource allocations (common in Linux kernel code).

Hindi mein samjhogoto labeled statement pe jump karta hai. Generally avoid karo — spaghetti code banta hai. Ek acceptable use: error cleanup jab multiple resources allocate kiye hon (Linux kernel me common hai).
💻 C — goto for error cleanup
int process_file(const char *path) {
    FILE *f = fopen(path, "r");
    if (!f) goto error_file;

    char *buf = malloc(1024);
    if (!buf) goto error_malloc;

    /* ... process data ... */

    free(buf);
    fclose(f);
    return 0;

error_malloc:
    fclose(f);
error_file:
    return -1;
}

Storage classes

Storage classes determine a variable's lifetime (how long it exists), scope (where it's accessible), and linkage (whether other files can see it). Understanding these is essential for multi-file C projects.

Hindi mein samjhoStorage classes variable ki lifetime (kitni der exist kare), scope (kahan accessible ho), aur linkage (doosri files dekh sake ya nahi) decide karte hain.
ClassLifetimeScopeDefault valueUse case
autoBlockLocalGarbageDefault for local vars (rarely written)
static (local)ProgramLocal0Persist value between function calls
static (global)ProgramFile only0Private to this .c file
externProgramGlobal0Share variable across files
registerBlockLocalGarbageHint: store in CPU register (rarely used)
💻 C — static local variable
void counter(void) {
    static int count = 0;  /* Initialized ONCE, persists */
    count++;
    printf("Called %d times\n", count);
}

int main(void) {
    counter();  /* Called 1 times */
    counter();  /* Called 2 times */
    counter();  /* Called 3 times */
    return 0;
}
Interview favorite: "What does static do?" — It has THREE meanings: (1) local variable that persists, (2) global variable private to file, (3) function private to file. Know all three.
