4.1

Defining functions — def, return, type hints

Building blocks of reusable code

Functions are defined with def, return values with return (returns None if omitted). Type hints (Python 3.5+) document expected types but are not enforced at runtime. Functions are first-class objects — they can be assigned, passed, and returned.

Hindi mein samjhoFunctions def se define hote hain, values return se return hoti hain (None return hota hai agar omit karo). Type hints (Python 3.5+) expected types document karte hain par runtime pe enforce nahi hote. Functions first-class objects hain — assign, pass, aur return ho sakte hain.
💻 Python — Defining functions
# Basic function
def greet(name):
    """Greet a person by name."""
    return f"Hello, {name}!"

result = greet("Yuvraj")  # "Hello, Yuvraj!"

# With type hints (Python 3.5+)
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b

# Multiple return values (returns tuple)
def min_max(numbers: list[int]) -> tuple[int, int]:
    return min(numbers), max(numbers)

lo, hi = min_max([3, 1, 4, 1, 5])  # lo=1, hi=5

# No return → returns None
def say_hello():
    print("Hello!")  # Side effect, no return

x = say_hello()  # x is None

# Functions are objects!
def square(x): return x ** 2
fn = square            # Assign to variable
fn(5)                  # 25
ops = [square, abs]   # Store in list
Type hints are documentation, not enforcement. Use mypy for static type checking: pip install mypy && mypy script.py
4.2

Arguments — positional, keyword, *args, **kwargs, / and *

Flexible function signatures

Python supports positional, keyword, default, *args (variable positional), and **kwargs (variable keyword) arguments. / forces positional-only, * forces keyword-only (Python 3.8+).

Hindi mein samjhoPython positional, keyword, default, *args (variable positional), aur **kwargs (variable keyword) arguments support karta hai. / positional-only force karta hai, * keyword-only force karta hai (Python 3.8+).
💻 Python — Arguments
# Default arguments
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

greet("Yuvraj")              # "Hello, Yuvraj!"
greet("Yuvraj", "Hi")       # "Hi, Yuvraj!"
greet(greeting="Hey", name="Bob")  # Keyword args

# *args — variable positional
def total(*numbers):
    return sum(numbers)

total(1, 2, 3)     # 6
total(10, 20)       # 30

# **kwargs — variable keyword
def build_profile(**info):
    return info

build_profile(name="Yuvraj", age=21)
# {'name': 'Yuvraj', 'age': 21}

# Combined (order matters!)
def func(a, b, *args, key="x", **kwargs):
    print(a, b, args, key, kwargs)

# Positional-only (/) and keyword-only (*)
def safe(x, /, *, mode="r"):
    pass
# safe(10, mode="w")  ✅
# safe(x=10)          ❌ x is positional-only

# ⚠️ MUTABLE DEFAULT TRAP!
# ❌ Bad:
def add_item(item, lst=[]):  # Shared across calls!
    lst.append(item)
    return lst

# ✅ Good:
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
Never use mutable defaults! def f(x=[]) creates ONE list shared across all calls. Always use None as default and create inside the function.
4.3

Lambda, map(), filter(), reduce()

Functional programming tools

lambda creates anonymous one-expression functions. map() transforms, filter() selects, reduce() aggregates. In modern Python, comprehensions are often preferred over map/filter.

Hindi mein samjholambda anonymous one-expression functions banata hai. map() transform karta hai, filter() select karta hai, reduce() aggregate karta hai. Modern Python me comprehensions map/filter se zyada prefer hote hain.
💻 Python — Lambda & functional
# Lambda — anonymous function
square = lambda x: x ** 2
square(5)  # 25

# Useful as sort key
students = [("Alice", 85), ("Bob", 92), ("Charlie", 78)]
students.sort(key=lambda s: s[1], reverse=True)
# [('Bob', 92), ('Alice', 85), ('Charlie', 78)]

# map() — transform each item
nums = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, nums))
# [1, 4, 9, 16]
# Comprehension equivalent: [x**2 for x in nums]

# filter() — keep matching items
evens = list(filter(lambda x: x % 2 == 0, nums))
# [2, 4]
# Comprehension equivalent: [x for x in nums if x % 2 == 0]

# reduce() — aggregate to single value
from functools import reduce
total = reduce(lambda a, b: a + b, nums)
# 10 (equivalent: sum(nums))

product = reduce(lambda a, b: a * b, nums)
# 24 (1 × 2 × 3 × 4)
4.4

Scope — LEGB rule, global, nonlocal

Where variables live

Python resolves variable names using the LEGB rule: Local → Enclosing → Global → Built-in. Use global to modify module-level variables, nonlocal for enclosing scope (closures).

Hindi mein samjhoPython variable names LEGB rule se resolve karta hai: Local → Enclosing → Global → Built-in. Module-level variables modify karne ke liye global, enclosing scope (closures) ke liye nonlocal use karo.
💻 Python — LEGB scope
# LEGB — Local, Enclosing, Global, Built-in
x = "global"      # G — global scope

def outer():
    x = "enclosing"  # E — enclosing scope

    def inner():
        x = "local"    # L — local scope
        print(x)       # "local"

    inner()
    print(x)  # "enclosing"

outer()
print(x)  # "global"

# global — modify module-level variable
count = 0
def increment():
    global count
    count += 1

increment()
print(count)  # 1

# nonlocal — modify enclosing variable
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

c = counter()
c()  # 1
c()  # 2
c()  # 3 — closure remembers n!

4.5

Modules & packages — import, __init__, __all__

Organizing code into files

A module is any .py file. A package is a directory with __init__.py. Use import to load modules, from...import for specific items. __all__ controls what from module import * exports.

Hindi mein samjhoEk module koi bhi .py file hai. Ek package ek directory hai jisme __init__.py ho. Modules load karne ke liye import, specific items ke liye from...import use karo. __all__ control karta hai ki from module import * kya export kare.
💻 Python — Modules & imports
# Import styles
import math
import math as m
from math import sqrt, pi
from math import *  # ❌ Avoid — pollutes namespace

# Using imported modules
math.sqrt(16)   # 4.0
m.pi            # 3.14159...
sqrt(25)        # 5.0

# __name__ — script vs module detection
if __name__ == "__main__":
    # Only runs when script is executed directly
    # NOT when imported as a module
    main()

# Package structure:
# mypackage/
#   __init__.py     ← makes it a package
#   module_a.py
#   module_b.py
#   subpkg/
#     __init__.py
#     module_c.py

# __all__ in __init__.py
__all__ = ["module_a", "module_b"]
if __name__ == "__main__" is the standard Python idiom. It ensures code only runs when the file is executed directly, not when imported.
4.6

Virtual environments — venv, pip, requirements.txt

Isolated dependency management

Virtual environments create isolated Python installations per project. Each venv has its own pip and packages. Use requirements.txt to reproduce environments. This prevents dependency conflicts between projects.

Hindi mein samjhoVirtual environments har project ke liye isolated Python installations banate hain. Har venv ka apna pip aur packages hota hai. Environments reproduce karne ke liye requirements.txt use karo. Ye projects ke beech dependency conflicts prevent karta hai.
💻 Terminal — venv workflow
# Create virtual environment
python -m venv .venv

# Activate
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # macOS/Linux

# Install packages (inside venv)
pip install requests flask numpy

# See installed packages
pip list
pip show requests

# Save dependencies
pip freeze > requirements.txt

# Reproduce on another machine
pip install -r requirements.txt

# Upgrade pip
pip install --upgrade pip

# Deactivate
deactivate

pip uninstall pkgRemove a package

pip freezeOutput requirements format
pip show pkgPackage info
pip install -r req.txtInstall from requirements
4.7

First-class functions, higher-order, functools

Functions as values

Functions are first-class objects — assigned to variables, stored in data structures, passed as arguments, returned from functions. functools provides partial(), lru_cache(), wraps(), and more.

Hindi mein samjhoFunctions first-class objects hain — variables me assign ho sakte hain, data structures me store, arguments me pass, aur functions se return ho sakte hain. functools me partial(), lru_cache(), wraps() jaise tools hain.
💻 Python — Higher-order & functools
# Higher-order: function takes function
def apply(func, value):
    return func(value)

apply(abs, -5)       # 5
apply(str.upper, "hi")  # "HI"

# Function factory — returns a function
def multiplier(n):
    def multiply(x):
        return x * n
    return multiply

double = multiplier(2)
triple = multiplier(3)
double(5)   # 10
triple(5)   # 15

# functools.partial — pre-fill arguments
from functools import partial

base2_log = partial(math.log, base=2)
base2_log(8)   # 3.0

# functools.lru_cache — memoization
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

fib(100)  # Instant! Without cache: heat death of universe
