Introduction to Python — History, Features, Why Python, Python 2 vs 3

What is Python?

Python is a high-level, interpreted, general-purpose programming language designed to prioritize readability and developer productivity. It allows developers to build scripts, web apps, automation tools, data pipelines, AI systems, and backend services with clear syntax and fast development speed.

Hindi mein samjhoPython ek readable aur powerful language hai jise beginner se lekar professional teams tak sab use karte hain. Iski syntax clean hai, isliye code samajhna aur maintain karna easy hota hai.

Quick history and growth

Python was created by Guido van Rossum and first released in 1991. Over time, it became one of the most adopted languages due to simplicity, huge library ecosystem, and strong community support.

Hindi mein samjhoPython 1991 se exist karta hai, aur aaj AI, web, data, automation har jagah use hota hai. Iski popularity ka reason hai simplicity + powerful ecosystem.

Why Python in 2026?

Python remains relevant because of versatile use-cases and strong job demand. Learning Python gives a practical base for full-stack development, data science, automation, cloud scripting, and interview preparation.

Hindi mein samjhoPython seekhne se aap multiple domains me switch kar sakte ho: web dev, data science, scripting, testing, AI. Career flexibility ke liye ye best language hai.

Python 2 vs Python 3

Python 2 is officially discontinued; modern development uses Python 3 only. Python 3 brings cleaner Unicode handling, better libraries, improved syntax features, and long-term ecosystem support.

Hindi mein samjhoPython 2 obsolete ho chuka hai. Hamesha Python 3 use karo, kyunki wahi supported hai aur industry standard bhi wahi hai.
Python 3 print style
print("Hello, Python 3!")
Hello, Python 3!
Example explained: In Python 3, print is a function and must use parentheses.

Environment Setup — Installation, IDE setup, first run

Install Python correctly

Correct installation ensures your terminal and IDE both use the same interpreter. Always verify with version commands immediately after installation.

Hindi mein samjhoInstall ke baad verify karna mandatory hai. Agar terminal aur IDE alag interpreter use karenge to confusion aur errors aayenge.
Verify installation
python --version
pip --version
Example explained: If commands return version numbers, installation is successful and PATH is configured.

Choose and configure IDE

VS Code and PyCharm are both good options. What matters most is selecting the correct interpreter and running code consistently.

Hindi mein samjhoIDE koi bhi use karo, but correct Python interpreter select karna sabse important step hai.

First Python program

Your first program validates the complete setup flow: file creation, script execution, output rendering.

Hindi mein samjhoPehla program run karke aap confirm karte ho ki environment properly setup hai.
hello.py
print("Welcome to CodeWithYuvraj Python Handbook!")
Example explained: Save as hello.py and run via terminal using python hello.py.
1.3

Variables & Data Types — int, float, str, bool, type(), casting

Variables and assignment

A variable is a named reference to a value object in memory. Clear naming and purposeful assignment are essential for maintainable code.

Hindi mein samjhoVariable ek label hai jo value ko hold karta hai. Meaningful names use karne se code readable banta hai.

Reference vs value (the mental model professionals use)

In Python, variables do not “store the value inside”; they store a reference to an object. This distinction explains many real bugs: when two variables refer to the same mutable object, a change through one name is visible through the other. This is why teams talk about shared state and side effects.

Hindi mein samjho Python me variable value ko “andar” store nahi karta — variable object ka reference store karta hai. Agar 2 variables same mutable object ko point kar rahe hain, to ek se change karoge to dusre me bhi change dikhega. Isi ko shared state / side effects bolte hain.
Python — shared reference example
a = [1, 2]
b = a
b.append(3)
print(a, b)
[1, 2, 3] [1, 2, 3]
Example explained: b = a copies the reference, not the list. Both names point to the same list object.

Core data types

Python includes numeric types (int, float), text type (str), and logical type (bool). Choosing the correct type improves validation and prevents logic bugs.

Hindi mein samjhoData type decide karta hai value ka behavior kya hoga. Sahi type choose karna bug prevention ka basic rule hai.
Python — basic types
age = 21
price = 99.5
name = "Yuvraj"
is_active = True
print(type(age), type(price), type(name), type(is_active))
Example explained: type() shows the runtime data type of each variable.

Type casting

Type casting converts values from one type to another when required for computation or formatting. Always validate values before conversion to avoid runtime errors.

Hindi mein samjhoCasting ka matlab type convert karna. User input string aata hai, use number banane ke liye int() ya float() use hota hai.
Python — casting
raw = "42"
num = int(raw)
print(num + 8)
50
Example explained: String "42" becomes integer 42, so arithmetic works correctly.
1.4

Operators — Arithmetic, Comparison, Logical, Assignment, Identity, Membership

Arithmetic and comparison operators

Arithmetic operators perform calculations while comparison operators produce boolean outputs for decisions. Together they power scoring, billing, eligibility, and validation logic.

Hindi mein samjhoArithmetic operators se calculation hota hai, comparison operators se decision ke liye True/False milta hai.
Python — arithmetic + comparison
a, b = 10, 3
print(a + b, a // b, a % b)
print(a > b, a == b)
Example explained: First line computes values; second line checks relationships and returns booleans.

Logical, identity, membership operators

Logical operators combine conditions, identity checks object reference equality, and membership checks value existence in a collection.

Hindi mein samjhoand/or/not conditions combine karte hain, is object identity check karta hai, aur in collection membership check karta hai.
Python — logical / identity / membership
age = 22
is_verified = True
print(age >= 18 and is_verified)

roles = ["user", "editor"]
print("admin" in roles)
Example explained: First check ensures both conditions are true; second checks if value exists inside list.
1.5

Input / Output — print(), input(), f-strings, formatting

print() and output formatting

print() is used to show output, logs, and debug values. Parameters like sep and end allow better output control.

Hindi mein samjhoprint() sirf text dikhane ke liye nahi, debugging aur readable output formatting ke liye bhi use hota hai.
Python — print formatting
print("Python", "Handbook", sep=" | ")
print("Loading", end="...")
print("Done")
Example explained: sep sets separator between values, and end changes line ending behavior.

input() and parsing

input() always returns a string, so numeric operations require parsing using int() or float().

Hindi mein samjhoUser se liya gaya input default string hota hai. Number calculations se pehle convert karna jaruri hai.
Python — input parsing
name = input("Enter name: ")
age = int(input("Enter age: "))
print(f"Hello {name}, next year you will be {age + 1}.")
Example explained: Name stays string, but age is converted to integer for arithmetic use.

Input validation mindset (industry pattern)

Real applications must treat user input as unreliable. Industry-grade programs validate format, range, and business rules before using values. A good pattern is: normalize → validate → convert → handle errors gracefully.

Hindi mein samjho Real apps me input ko trust nahi karte. Pehle normalize (strip/lower), phir validate (empty/range), phir convert, aur error ko gracefully handle karte hain. Yehi production-ready input handling pattern hai.
Python — safe input loop
while True:
    raw = input("Enter age (18-99): ").strip()
    if not raw.isdigit():
        print("Please enter a number.")
        continue
    age = int(raw)
    if age < 18 or age > 99:
        print("Age out of allowed range.")
        continue
    print("Accepted age:", age)
    break
Example explained: Program validates numeric input and range before using the value.
1.6

Comments & Documentation — single-line, block style, docstrings

Comments for maintainability

Comments explain intent and context where code alone is not enough. Good comments reduce onboarding time and prevent misunderstandings in team collaboration.

Hindi mein samjhoComments ka use code ka logic explain karne ke liye karo, especially tricky places par. Ye team work me bahut helpful hota hai.
Python — comments
# Calculate final amount after GST
price = 1200
gst = 0.18
final_amount = price + (price * gst)
Example explained: The comment explains business purpose of the formula before code execution.

Docstrings and help()

Docstrings are structured documentation strings attached to modules, classes, and functions. Tools and developers use them via help() and autogenerated documentation workflows.

Hindi mein samjhoDocstring professional documentation hota hai jo function/class ke purpose aur usage ko clear karta hai.
Python — docstring
def calculate_gst(amount, rate):
    """Return total amount after GST.

    Args:
        amount (float): base amount
        rate (float): GST rate in decimal form
    """
    return amount + amount * rate

print(calculate_gst(1000, 0.18))
1180.0
Example explained: Function behavior is documented inside docstring, making the function easier to use and review.
