What is Python — history, CPython, PyPy, versions

The world's most popular programming language

Python was created by Guido van Rossum in 1991. It's a high-level, interpreted, dynamically-typed language with clean syntax. Python emphasizes readability — code should read like English. Used in web dev, AI/ML, data science, automation, and scripting.

Hindi mein samjhoPython Guido van Rossum ne 1991 me banaya tha. Ye high-level, interpreted, dynamically-typed language hai jiska syntax clean hai. Python readability pe focus karta hai — code English jaisa padha jaaye. Web dev, AI/ML, data science, automation me use hota hai.
💻 Python — Hello World
# Your first Python program
print("Hello, World!")

# Python is interpreted — no compilation needed!
# Just run: python hello.py

# Check your Python version
import sys
print(sys.version)  # 3.12.0 (or whatever you have)

Setup & IDE — pip, venv, VS Code, Jupyter

Setting up your development environment

Install Python from python.org (always check "Add to PATH"). Use pip for packages, venv for isolated environments. VS Code with the Python extension is the best free IDE. Jupyter Notebooks are great for data science.

Hindi mein samjhoPython python.org se install karo (hamesha "Add to PATH" check karo). Packages ke liye pip, isolated environments ke liye venv use karo. VS Code Python extension ke saath best free IDE hai. Data science ke liye Jupyter Notebooks best hain.
💻 Terminal — Setup commands
# Check Python installation
python --version        # Python 3.12.0
pip --version           # pip 24.0

# Create virtual environment
python -m venv myproject
myproject\Scripts\activate   # Windows
source myproject/bin/activate # macOS/Linux

# Install packages
pip install requests
pip install numpy pandas matplotlib
pip freeze > requirements.txt

# Install from requirements
pip install -r requirements.txt

# Jupyter Notebook
pip install jupyter
jupyter notebook

Variables & data types — int, float, str, bool, None

No type declarations needed

In Python, you don't declare types — the interpreter infers them. Variables are just names pointing to objects. Python has int, float, str, bool, None, complex, bytes as built-in types. Everything in Python is an object.

Hindi mein samjhoPython me type declare nahi karna padta — interpreter khud samajh leta hai. Variables sirf names hain jo objects ko point karte hain. Built-in types: int, float, str, bool, None. Python me sab kuch object hai.
💻 Python — Variables & types
# No type declaration needed
name = "Yuvraj"          # str
age = 21                  # int
gpa = 9.5                 # float
is_student = True         # bool
nothing = None            # NoneType

# Check type
print(type(name))   # <class 'str'>
print(type(age))    # <class 'int'>

# Multiple assignment
x, y, z = 1, 2, 3
a = b = c = 0

# Python integers have unlimited precision!
big = 10 ** 100  # No overflow — works fine

# id() — memory address of object
print(id(name))   # e.g., 140234567890

# Variables are references, not boxes
a = [1, 2, 3]
b = a              # b points to SAME list
b.append(4)
print(a)           # [1, 2, 3, 4] — both changed!

Operators — arithmetic, comparison, logical, bitwise, walrus

Building expressions

Python has all standard operators plus some unique ones: // for integer division, ** for power, := (walrus operator, Python 3.8+) for assignment expressions, and is for identity comparison.

Hindi mein samjhoPython me standard operators ke saath kuch unique bhi hain: // integer division ke liye, ** power ke liye, := (walrus operator) assignment expressions ke liye, aur is identity comparison ke liye.
💻 Python — Operators
# Arithmetic
10 + 3    # 13
10 - 3    # 7
10 * 3    # 30
10 / 3    # 3.3333 (true division)
10 // 3   # 3 (floor division)
10 % 3    # 1 (modulo)
2 ** 10   # 1024 (power)

# Comparison
5 == 5    # True (equality)
5 != 3    # True
5 > 3     # True

# Logical
True and False   # False
True or False    # True
not True         # False

# Identity & Membership
a is b         # Same object in memory?
x in [1,2,3]   # Membership check

# Walrus operator := (Python 3.8+)
if (n := len(data)) > 10:
    print(f"Too long: {n} items")

Input/Output — print(), input(), f-strings, formatting

Talking to the user

print() outputs to console, input() reads from keyboard (always returns str). f-strings (Python 3.6+) are the fastest and cleanest way to format strings. Use format specifiers for numbers.

Hindi mein samjhoprint() console pe output deta hai, input() keyboard se padta hai (hamesha str return karta hai). f-strings (Python 3.6+) sabse fast aur clean string formatting hai. Numbers ke liye format specifiers use karo.
💻 Python — I/O & f-strings
# Basic print
print("Hello")
print("A", "B", "C", sep="-")  # A-B-C
print("No newline", end=" ")

# Input (always returns str!)
name = input("Enter name: ")
age = int(input("Enter age: "))  # Must convert!

# f-strings — the modern way (Python 3.6+)
name = "Yuvraj"
age = 21
print(f"Name: {name}, Age: {age}")

# f-string expressions
print(f"2 + 3 = {2 + 3}")
print(f"{name.upper()}")       # YUVRAJ
print(f"{name!r}")             # 'Yuvraj' (repr)

# Number formatting
pi = 3.14159
print(f"Pi: {pi:.2f}")          # Pi: 3.14
print(f"Big: {1000000:,}")     # Big: 1,000,000
print(f"Pct: {0.85:.1%}")      # Pct: 85.0%
print(f"Hex: {255:#x}")        # Hex: 0xff
print(f"Pad: {42:05d}")        # Pad: 00042

Type conversion & type checking — int(), str(), isinstance()

Converting between types

Python provides built-in functions for explicit type conversion: int(), float(), str(), bool(), list(), tuple(). Use isinstance() for type checking (preferred over type()).

Hindi mein samjhoPython me explicit type conversion ke liye built-in functions hain: int(), float(), str(), bool(). Type checking ke liye isinstance() use karo (type() se better hai).
💻 Python — Type conversion
# Explicit conversion
int("42")        # 42
float("3.14")    # 3.14
str(42)          # "42"
bool(0)          # False
bool("")         # False
bool("hello")    # True
list("abc")      # ['a', 'b', 'c']

# Falsy values in Python
# False, 0, 0.0, "", [], {}, (), set(), None, range(0)

# Type checking
isinstance(42, int)           # True
isinstance("hi", (str, bytes)) # True (tuple = OR)
type(42) == int               # True (but less flexible)
type(42).__name__              # "int"
Prefer isinstance() over type() — it respects inheritance. isinstance(True, int) is True because bool is a subclass of int.

Comments, docstrings, PEP 8 style guide

Writing clean, readable code

PEP 8 is Python's official style guide. Use # for comments, triple-quotes for docstrings. Follow 4-space indentation, snake_case naming, and 79-char line limit. Clean code is professional code.

Hindi mein samjhoPEP 8 Python ka official style guide hai. Comments ke liye #, docstrings ke liye triple-quotes use karo. 4-space indentation, snake_case naming, aur 79-char line limit follow karo. Clean code = professional code.
💻 Python — PEP 8 style
# Single-line comment

"""
Multi-line docstring.
Used for modules, classes, and functions.
"""

def calculate_area(radius: float) -> float:
    """Calculate the area of a circle.

    Args:
        radius: The radius of the circle.

    Returns:
        The area as a float.
    """
    import math
    return math.pi * radius ** 2

# ✅ PEP 8 naming conventions
my_variable = 42          # snake_case for variables
MY_CONSTANT = 3.14        # UPPER_CASE for constants
class MyClass:             # PascalCase for classes
    pass
def my_function():        # snake_case for functions
    pass
_private_var = 10         # leading _ for "private"
