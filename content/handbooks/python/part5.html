5.1

Class and Object Fundamentals

What are classes and objects?

A class is a blueprint that defines attributes (state) and methods (behavior), while an object is a concrete runtime instance of that blueprint. OOP helps model real entities and business workflows in a structured way, making systems easier to extend and maintain as complexity grows.

Hindi mein samjhoClass ek design template hai aur object uska real runtime instance. OOP se aap real-world entities (user, order, account) ko clean structure me model kar sakte ho.

Creating first class

Use class syntax to define properties and methods. Object behavior is accessed through dot notation, which binds method calls to specific object state. This object-method binding is what enables reusable logic with instance-specific behavior.

Hindi mein samjhoClass ke andar attributes aur methods define karte hain. Jab object se method call hota hai to wahi method object ke current data ke saath execute hota hai.
Python — class and object
class Student:
    def introduce(self):
        print("I am a student")

s1 = Student()
s1.introduce()
I am a student
Example explained: Student is blueprint; s1 is actual object calling method.
5.2

Constructors and Instance Attributes

Role of __init__

Constructor initializes object state when object is created. It ensures each object starts with valid required values. In professional design, constructors often enforce baseline invariants so invalid object states are prevented from the beginning.

Hindi mein samjho__init__ object creation ke time initial values set karta hai. Advanced use me constructor validation bhi karta hai taaki object invalid state me create na ho.

Parameterized object creation

Pass values during object creation to produce custom instances from the same class. This allows one class definition to represent many domain entities with different state values.

Hindi mein samjhoEk hi class se multiple objects ban sakte hain jinke values alag-alag hote hain. Isi se reusable domain modeling possible hoti hai.
Python — constructor usage
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

p = Product("Keyboard", 1499)
print(p.name, p.price)
Keyboard 1499
Example explained: Constructor receives values and stores them in object attributes.
5.3

Encapsulation — Data Protection and Controlled Access

Encapsulation basics

Encapsulation bundles data and behavior together and restricts unsafe external state changes. Sensitive attributes should be modified through controlled methods where validation, logging, and constraints can be applied.

Hindi mein samjhoEncapsulation ka objective hai sensitive data ko direct access se protect karna. State update methods ke through hota hai jahan rules apply kiye ja sakte hain.

Private-like attributes convention

Python uses naming conventions like _name and __name to indicate protected/private intent. While not absolute security, these conventions communicate design boundaries and reduce accidental misuse.

Hindi mein samjhoSingle underscore protected intent dikhata hai aur double underscore name-mangling karta hai. Ye strict security nahi hai, lekin design discipline enforce karta hai.
Python — encapsulation example
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
    def get_balance(self):
        return self.__balance

acc = BankAccount(1000)
acc.deposit(500)
print(acc.get_balance())
1500
Example explained: Balance is not directly modified from outside; updates go through methods.
5.4

Inheritance — Reusing and Extending Behavior

Why inheritance?

Inheritance lets child classes reuse parent functionality and add specialized behavior, reducing duplicated code. It should be used where a true "is-a" relationship exists; otherwise composition is often safer and more flexible.

Hindi mein samjhoInheritance tabhi use karo jab real "is-a" relation ho (jaise Car is a Vehicle). Galat use se tight coupling aur maintenance issues badh sakte hain.

Parent-child example

Child class inherits parent methods automatically and can override methods when required. Method overriding enables specialization while preserving shared interface contracts.

Hindi mein samjhoChild class parent methods inherit karti hai aur zarurat par same method ka customized version likh sakti hai. Isse shared contract rehta hai lekin behavior specific ban jata hai.
Python — inheritance
class Vehicle:
    def start(self):
        print("Vehicle started")

class Car(Vehicle):
    def start(self):
        print("Car engine started")

c = Car()
c.start()
Car engine started
Example explained: Car inherits from Vehicle and overrides start().
5.5

Polymorphism — Same Interface, Different Behavior

Polymorphism concept

Polymorphism allows writing generic code that works with different object types through a shared method interface. This decouples caller logic from concrete class types and improves extensibility.

Hindi mein samjhoPolymorphism se caller ko object type details ki zarurat nahi padti; shared method interface enough hota hai. Isse system me naye types add karna easy hota hai.

Duck typing style

Python follows duck typing: if an object supports the required behavior, it can be used. This favors protocol-like design where capabilities matter more than inheritance hierarchy.

Hindi mein samjhoPython behavior-driven language hai: agar required method present hai to object valid maana jata hai. Is approach se flexible design possible hota hai.
Python — polymorphism
class Dog:
    def speak(self):
        print("Woof")

class Cat:
    def speak(self):
        print("Meow")

for animal in [Dog(), Cat()]:
    animal.speak()
Woof\nMeow
Example explained: Loop calls same method speak() but output changes by object type.
5.6

Abstraction — Expose Essentials, Hide Complexity

Abstraction in design

Abstraction means exposing only necessary interface while hiding implementation details. It reduces cognitive load for users of your code and allows internals to evolve without breaking external usage.

Hindi mein samjhoAbstraction ka fayda hai simple interface. User ko internal complexity samajhne ki zarurat nahi padti, aur implementation future me safely change ki ja sakti hai.

Abstract base class example

Use abc module to define contracts that child classes must implement. This ensures consistent interfaces across implementations and catches missing methods early.

Hindi mein samjhoAbstract base class interface contract enforce karti hai. Agar child required method implement na kare to design error early stage me hi catch ho jata hai.
Python — abstraction
from abc import ABC, abstractmethod

class Payment(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class UPIPayment(Payment):
    def pay(self, amount):
        print(f"Paid {amount} via UPI")

UPIPayment().pay(799)
Paid 799 via UPI
Example explained: Payment defines contract; UPIPayment provides actual implementation.
5.7

Magic Methods — __str__, __len__, Operator Behavior

What are magic methods?

Magic (dunder) methods allow custom object behavior for built-in operations like printing, length, addition, and comparisons. They make custom classes feel native within Python expressions and standard APIs.

Hindi mein samjhoMagic methods se custom objects Python ecosystem me naturally behave karte hain. Isse class usability aur developer experience dono improve hote hain.

Custom representation and length

Implement __str__ for readable output and __len__ to support len(obj). These methods improve debugging clarity and allow objects to integrate with common built-in workflows.

Hindi mein samjho__str__ readable display deta hai aur __len__ object ko built-in len() ke saath compatible banata hai. Ye debugging aur usability dono enhance karta hai.
Python — magic methods
class Playlist:
    def __init__(self, songs):
        self.songs = songs
    def __str__(self):
        return f"Playlist with {len(self.songs)} songs"
    def __len__(self):
        return len(self.songs)

p = Playlist(["Song A", "Song B"])
print(p)
print(len(p))
Playlist with 2 songs\n2
Example explained: Object now behaves naturally with print() and len().
