3.1

Strings — Creation, Indexing, Slicing, Common Methods

What is a string in Python?

A string is an ordered sequence of Unicode characters used to represent text data. In real-world applications, strings handle names, emails, logs, user messages, file paths, API payloads, and more. Strings are immutable, which means every modification operation returns a new string object.

Hindi mein samjho String text data store karta hai, jaise username, email, message, logs. Python mein strings immutable hoti hain, yani change karne pe naya string banta hai.

Unicode + encoding (real-world production detail)

Python strings are Unicode, which means they can represent characters from many languages (Hindi, Marathi, emojis, etc.). When you read/write files or interact with APIs, you are often converting between text (Unicode) and bytes (encoded form like UTF-8). Most bugs happen when encoding is not specified consistently.

Hindi mein samjho Python strings Unicode hote hain, isliye Hindi/Marathi/emoji sab support hota hai. File aur APIs ke time text ko bytes me encode/decode karna padta hai (UTF-8 common hai). Encoding specify na karne se real projects me bugs aate hain.
Python — encoding demo
s = "नमस्ते Python"
b = s.encode("utf-8")
print(b)
print(b.decode("utf-8"))
Example explained: Text becomes bytes via encode(), then returns to text via decode().

Indexing and slicing

Indexing gives direct access to a single element by position, while slicing extracts a contiguous range of elements. Python supports both positive indexing (left to right) and negative indexing (right to left), which makes boundary access very convenient. In practical text-processing tasks, slicing is frequently used for token extraction, prefix/suffix checks, masking sensitive values, and preprocessing data.

Hindi mein samjho Indexing se ek specific position ka character milta hai, aur slicing se range ke characters milte hain. Negative indexing se aap end side se access kar sakte ho, jo real projects mein last characters, extensions, ya suffix check ke liye kaafi useful hota hai.
Python — indexing and slicing
text = "CodeWithYuvraj"
print(text[0])      # C
print(text[-1])     # j
print(text[0:4])    # Code
print(text[4:8])    # With
Example explained: Single index returns one character; slice start:end returns characters from start to end-1.

Useful string methods

String methods are essential for normalization, cleaning, and controlled transformation of text inputs. In production code, user input almost always needs preprocessing before validation or storage. Common methods include lower(), upper(), strip(), replace(), and split(), each solving a specific cleaning step.

Hindi mein samjhoString methods data cleaning pipeline ka core hote hain. User se aaya raw text directly reliable nahi hota, isliye normalize karke hi aage process karna chahiye.
Python — string cleanup
raw = "  PYTHON,java,Go  "
clean = raw.strip().lower().replace("go", "golang")
langs = clean.split(",")
print(langs)
['python', 'java', 'golang']
Example explained: Spaces removed by strip(), case normalized by lower(), and text transformed using replace().
3.2

Lists — Mutable Ordered Collections

What is a list?

A list is an ordered, mutable collection that can store mixed data types. Lists are heavily used for task queues, item catalogs, marks tables, API response handling, and dynamic datasets. Because lists are mutable, they are ideal where data changes frequently during program execution.

Hindi mein samjhoList ordered aur mutable collection hai, isliye runtime mein items add/remove/update karna easy hota hai. Dynamic workflows ke liye list sabse common aur practical choice hai.

Core list operations

Learn append, insert, remove, pop, and slicing for efficient daily work. Understanding these operations reduces errors in dynamic list management and helps you reason about state changes clearly. In interviews and production code, many bugs come from incorrect assumptions about whether an operation mutates list in-place or returns a new object.

Hindi mein samjhoList operations se data maintain hota hai: add, delete, update, extract. Advanced level par yeh samajhna important hai ki kaunsa method list ko directly change karta hai aur kaunsa new value return karta hai.
Python — list operations
items = ["pen", "book", "laptop"]
items.append("mouse")
items.insert(1, "notebook")
items.remove("pen")
last = items.pop()
print(items)
print(last)
['notebook', 'book', 'laptop']\nmouse
Example explained: append() adds at end, insert() adds at position, remove() deletes by value, and pop() returns removed item.

Performance intuition (Big-O) — choose the right tool

Industry code often fails performance not because Python is slow, but because the wrong data structure is used. Basic intuition: list membership checks are linear, while set/dict membership is usually constant time. This directly impacts search-heavy tasks.

Hindi mein samjhoPerformance ka biggest lever hota hai correct data structure. List me membership check slow (linear) hota hai, set/dict me usually fast (constant) hota hai.
OperationListSet/Dict
Membership (x in ...)O(n)≈ O(1)
Append≈ O(1)≈ O(1)
Insert at startO(n)n/a
3.3

Tuples — Immutable Ordered Collections

Why tuples exist?

Tuples are ordered but immutable sequences, useful when data should remain constant. They are suitable for coordinates, fixed configuration values, and dictionary keys. Immutability communicates intent: "this structure should not change", which improves code reliability and predictability.

Hindi mein samjhoTuple fixed contract jaisa hota hai. Jab data stable hona chahiye tab tuple best hai, kyunki accidental modification ka risk kam ho jata hai.

Tuple unpacking

Unpacking allows assigning tuple values into multiple variables in one line. This pattern improves readability and is common in loops and function returns.

Hindi mein samjhoTuple unpacking se ek line mein multiple variables assign ho jate hain.
Python — tuple unpacking
point = (10, 25)
x, y = point
print(x, y)
10 25
Example explained: Tuple’s first value goes to x, second goes to y automatically.
3.4

Dictionaries — Key-Value Data Modeling

What is a dictionary?

A dictionary stores data in key-value pairs for fast lookup by key. It is ideal for modeling JSON-like data such as user profiles, product details, and configuration objects. Compared to list scanning, keyed lookup in dictionaries is significantly more efficient for retrieval-heavy workflows.

Hindi mein samjhoDictionary ka strength hai fast key-based access. API data, configs, profile objects jaise structured information ke liye dictionary most practical structure hai.

Common dictionary operations

Practice create/read/update/delete (CRUD), get(), and iteration. get() is safer than direct indexing when key may not exist. Mature dictionary handling includes safe defaults, predictable key naming, and explicit handling of missing fields.

Hindi mein samjhoDictionary access mein missing keys common hoti hain, especially API data mein. Isliye get() + default value use karna safer aur production-friendly approach hai.
Python — dictionary CRUD
user = {"name": "Yuvraj", "role": "admin"}
user["city"] = "Pune"
user["role"] = "mentor"
print(user.get("email", "not provided"))
for k, v in user.items():
    print(k, "->", v)
Example explained: Dictionary was updated dynamically and iterated using items() for key-value access.
3.5

Sets — Unique Values and Fast Membership Checks

Why use sets?

A set stores unique unordered values and automatically removes duplicates. It is highly useful for membership checks and operations like union, intersection, and difference. For repeated existence checks, sets often outperform lists due to their hash-based lookup behavior.

Hindi mein samjhoSet duplicates automatically remove karta hai aur membership checks fast banata hai. Data deduplication aur overlap analysis ke liye set bahut powerful tool hai.

Set operations in practice

Use set math to compare groups, detect overlaps, and find missing entries. This is common in permission systems, tags, recommendation engines, and analytics.

Hindi mein samjhoSet operations se common, extra, aur missing values quickly nikal sakte ho.
Python — set math
a = {1, 2, 3, 4}
b = {3, 4, 5}
print(a | b)   # union
print(a & b)   # intersection
print(a - b)   # difference
Example explained: Union combines all unique values, intersection gives common values, and difference gives values only in first set.
3.6

Comprehensions — Compact Data Transformation

What are comprehensions?

Comprehensions provide concise syntax to create new collections from iterables. Python supports list, set, and dictionary comprehensions for transform + filter workflows. They improve readability when logic is simple and predictable. Use comprehensions when they reduce ceremony without hiding intent; for multi-step logic, explicit loops remain more maintainable.

Hindi mein samjhoComprehension concise syntax deta hai, lekin readability first rule hai. Simple map/filter cases mein best hai, complex transformations mein normal loop zyada clear hota hai.

List, set, and dict comprehension examples

Use comprehensions for mapping and filtering data. Avoid over-complex one-liners; if expression becomes hard to read, use normal loops.

Hindi mein samjhoSimple transformation ke liye comprehension best hai. Complex condition ho to readable loop likhna better hai.
Python — comprehensions
nums = [1, 2, 3, 4, 5, 6]
squares = [n * n for n in nums if n % 2 == 0]
unique_chars = {c.lower() for c in "CodeWithYuvraj"}
marks = {name: len(name) * 10 for name in ["Asha", "Ravi", "Meena"]}
print(squares)
print(unique_chars)
print(marks)
Example explained: First line builds even-number squares, second builds a unique lowercase character set, third builds a derived dictionary.
